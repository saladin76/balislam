# تقييم AlQuran.cloud ضمن خطة تطوير عرض القرآن في الاستوديو

الحالة: **إضافة مرجعية لخطة التطوير؛ لا تكامل API ولا تغيير لمصدر النص القرآني المعتمد قبل المراجعة الشرعية والتقنية.**

## المراجع التي طلب صاحب المشروع تقييمها

1. API الآيات: https://alquran.cloud/api#tag/ayah
2. دليل بيانات التجويد وألوان الأحكام: https://alquran.cloud/tajweed-guide
3. أداة مقارنة الخطوط والطبعات العربية: https://alquran.cloud/arabic-font-edition-tester

## مواضع الاستفادة المقترحة

- **جلب الآيات:** دراسة نداءات الآية والطبعات والبيانات الوصفية واختبار اختلاف الرسم العثماني والضبط وعلامات الوقف مقارنةً بالمصدر المعتمد في القناة (Quran Foundation).
- **التجويد:** استخدام دليل الوسوم وألوان الأحكام للتجارب التعليمية فقط بعد فحص صيغة الوسوم والتحقق من دقة التطبيق. لا يغيّر ترميز التجويد النص القرآني الأساس ولا يُحرّك بطاقات الآيات تلقائيًا.
- **الخطوط:** اختبار عرض نصوص الرسم العثماني على الخطوط المناسبة، والتأكد من اتصال الحروف وعلامات الوقف والتشكيل عبر 16:9 و9:16 والهاتف.
- **التحقق المزدوج:** عند اختلاف نص أو علامات ضبط أو طبعة، أوقف الاعتماد وسجّل الفروق ليتحقق منها المراجع الشرعي؛ لا تختار الآية «الأفضل شكلًا» على حساب النص.
- **التراخيص والأداء:** تأكد من الشروط، وحدود النداءات، والإصدارات، والتخزين المؤقت، وإمكانية استخدام الخطوط في الفيديوهات التجارية قبل دمج أي مصدر.

## موقعها في خارطة المراحل

- **بعد استعادة سلامة الاختبارات** وقبل اعتماد المرحلة الثالثة «الآيات والإضاءة والعمق»: نفّذ نموذج تحقق مستقل للنص والتجويد والخط.
- المرحلة الثالثة: اختبار بطاقة الآية الساكنة مع الخط المعتمد وعدم تغيير النص أو الأحكام.
- لا نضيف محرك قرآن موازيًا؛ نعتمد واجهة مصدر واحدة ومزوّدًا إضافيًا فقط عند إثبات ضرورة واضحة، مع حماية مسار الإنتاج الحالي.
- احتفظ بمصدر القرآن الحالي مصدرًا أساسيًا حتى يصدر قرار اعتماد صريح.

## اختبار القبول

1. مقارنة عينات موثقة من آيات قصيرة وطويلة ومن علامات وقف متنوعة، مع المرجع المعتمد.
2. اختبارات لسلامة Unicode والتشكيل واتجاه الكتابة والتقسيم على الأسطر.
3. معاينات عرض 16:9 و9:16 على الهاتف بعد تصريح الرندر.
4. عدم إدخال أي حركة زخرفية في الآية الساكنة.
5. مراجعة شرعية للنص والتجويد؛ ومراجعة ترخيص الخط والمصدر.
6. عدم التأثير في القنوات الأخرى أو النسخ المنشورة.

**لا يوجد تنفيذ تكاملي لهذه الروابط في هذه الإضافة.**
