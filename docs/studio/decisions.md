# جدول القرارات وحالاتها

> **ما هذا الملف:** كل قرار `Dنن` في سجلات القنوات الثلاث مرة واحدة: تاريخه، وسطر واحد (عنوانه في سجل التعريف)، وحالته اليوم. يجعل سلسلة الإلغاءات مرئية في مكان واحد (العمل ٥، D113).
> **المصدر:** نص القرار وتفصيله في سجل التعريف: `docs/balislam/06-decisions.md` و`docs/dafatir-alzaman/07-decisions.md` و`docs/zubdat-alkutub/06-decisions.md`. أرقام القرارات مشتركة بين القنوات (`scripts/decisions.mjs`). السلوك الحالي كله في `docs/studio/studio-map.md`.
> **الحالات:** «سارٍ» = لم يُلغه قرار بعده. «أُلغي بـ Dنن» = بطل كله. «حل محله Dنن» = قرار أحدث يقوم مقامه. «أُلغي جزئيًا بـ Dنن» = بطل الجزء المذكور وحده، والباقي سارٍ. القرارات الخاصة بحلقة (توجيه أو نسخة) سارية لتلك الحلقة ما لم يُذكر غير ذلك.
> **التحديث:** مع كل قرار جديد يُضاف صفه هنا في commit القرار نفسه، وإن ألغى قرارًا أو حل محله تتغير حالة ذاك هنا وفي الخريطة. يفحصه `tests/decisions-table.test.ts`.
