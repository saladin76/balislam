# Studio V2 — Phase E1: فحص بنية الفيديو المركب AV عند تقديم واعتماد المشهد

**الحالة:** كود جديد في PR #77 على فرع معزول، **لم يتم تشغيل اختباراته على Mac بعد**. نتيجة Phase D2 المعتمدة فقط على \`c42917c\`: TypeScript و62/62 اختبار V2 و739/739 اختبار المشروع في 94 ملفًا.

## المنفذ

- \`src/workflow/sceneMediaV2.ts\`: تشغيل \`ffprobe\` من مسار تنفيذي مطلق **يحدده الخادم الموثوق**؛ لا يُقبل أمر Shell أو مسار من طلب HTTP. تعمل العملية بدون Shell وببيئة محدودة لا تحتوي مفتاح توقيع السجل، وبحد أقصى لزمن التنفيذ وحجم الناتج.
- فحص الملف الفعلي داخل نطاق الحلقة: **حاوية MP4**، مسار فيديو واحد معروف، أبعاد معقولة، مدة إيجابية، والتحقق من وجود مسار صوت معروف عند وضع \`narrated\` أو \`recitation\` أو \`mixed\`. أما \`silent\` فيسمح بفيديو بلا مسار صوت، كما يسمح بمؤثرات أو موسيقى/صوت بيئة دون ادعاء وجود تعليق.
- إعادة قراءة SHA-256 وgeneration/epoch للـMP4 بعد فحصه لاكتشاف أي تغيير أثناء الفحص، حتى لو لم يتغير الاسم. جميع العمليات يجب أن تكون تحت **نفس قفل الكتابة** للمشهد والأصول.
- \`src/workflow/sceneServiceV2.ts\`: استدعاء الفاحص أثناء \`submit\`، ثم بعد فحص دليل مراجعة المالك وعند \`approve\` **قبل** اعتماد السجل الموقّع. غياب إعداد \`ffprobeBinary\` يوقف إنشاء الخدمة؛ غياب \`ffprobe\` الفعلي يوقف القرار، لا يمنح موافقة صامتة.
- \`tests/workflow-scene-media-v2.test.ts\`: 14 اختبارًا باستخدام ملفات مؤقتة حقيقية **لكن ببايتات MP4 اصطناعية وبعملية ffprobe محاكاة معزولة**. يغطي صوت مفقود، فيديو مفقود، مدة وأبعاد غير صالحة، حاوية ملف خاطئة، تعديل الملف أثناء الاستجواب، استجابة تالفة/تعليق أداة الفحص، عزل سر HMAC ومسارات غير آمنة.
- \`tests/workflow-scene-service-v2.test.ts\`: اختباران إضافيان يؤكدان أن خدمة \`submit\` ترفض MP4 بلا فيديو أو بلا مسار صوت مطلوب، ولا تعامله على أنه مراجعة مكتملة.

**التوقع:** 78 اختبارًا لـV2 في 7 ملفات (62 السابقة + 14 media + 2 service)؛ إجمالي المشروع المتوقع 755، **غير مؤكد قبل تشغيل Mac**.

## ما ليس مثبتًا بعد

1. **تجربة MP4 حقيقي:** اختبارات الفاحص تحاكي JSON الذي ترجعه \`ffprobe\` ولا تثبت تشغيل محركه على فيلم مشهد منتج. يجب تنفيذ Smoke Tests بملفي MP4 حقيقيين (صامت ومنطوق) على Mac وبـ\`ffprobe\` حقيقي، ومقارنة نتيجة رندر Remotion؛ يرفض النظام الإنتاج عند عدم توفر الأداة.
2. **صدق سجل المشاهدة:** فحص المسارات لا يثبت مشاهدة المالك للمشهد 1× ولا صحة التلاوة ومزامنتها. \`verifyCurrentSceneAvReview()\` يحتاج متحققًا مستقلًا موثقًا، ولا يجوز استبداله بـ\`confirmWatched=true\` أو رد اتصال لا يفعل شيئًا.
3. **تحقق صوتي دلالي:** وجود مسار AAC لا يثبت أنه يحتوي التسجيل المطلوب أو أن تلاوة القرآن بشرية؛ تحتاج مطابقة مراجعة الحقوق والتسجيل والتوقيت بالنص المصرّح به.
4. **تكامل الرندر:** لم يربط الكود نقاط HTTP أو CLI أو طابور الرندر أو Master أو النشر. ما زال الرندر القديم يعمل وفق عقده الحالي، وليس محرك V2.
5. **قفل مشترَك فعلي:** محول الخدمة معتمد على \`withArtifactLock\` مزود موثوق؛ يجب ضمان أن جميع كتّاب ملفات الصوت/السيناريو/الفيديو يستخدمونه قبل تفعيل مسار القرار الإنتاجي.

**المطلوب في Mac QA:** \`npm run typecheck\`، تشغيل 7 ملفات اختبارات Studio V2، ثم \`npm run check\` كاملًا. يعمل داخل Worktree المعزول فقط. لا Merge إلى \`main\` ولا أي كتابة في ملفات الحلقات.
