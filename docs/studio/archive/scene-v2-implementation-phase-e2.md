# Studio V2 — E2: اختبار وسائط AV حقيقية دون المساس بالحلقات

**مرجع الاختبارات الناجحة السابق:** E1 عند \`4fe11f9867d5cca19bb065c8cc2f27a3846b03c8\` على Mac: **78/78** اختبارات V2، **755/755** اختبارات المشروع ضمن **95/95** ملفًا، وTypeScript نجح، و\`ffmpeg\` و\`ffprobe\` متاحان تحت \`/opt/homebrew/bin/\`. هذا النجاح **لا يشمل E2**.

## ما أُضيف

- \`tests/scene-real-av-smoke.ts\`: سكريبت QA مُنفصل لا يدخل ملفات اختبارات Vitest ولا يستخدم حلقات الإنتاج.
- ينشئ مجلدًا عشوائيًا داخل \`TMPDIR\`، به قناة/حلقة QA مؤقتة \`balislam/episodes/001-real-av-qa\`، وملفات \`script.md\` و\`plan.json\` ومدخلات المشاهد الأساسية. لا يقرأ أو يكتب مطلقًا في \`channels/\` الحقيقي.
- يشغّل **FFmpeg الحقيقي** لتوليد مشهد مرئي صامت ببيانات MP4 حقيقية، ومشهد متحرك مع مسار صوتي AAC، وMP4 صوتي بلا فيديو، وWAV محلي يُمثّل مدخل الراوي لأغراض الفحص فقط. **نغمة الاختبار ليست أداءً بشريًا ولا تلاوة ولا إثباتًا لحقوق الصوت**.
- يستدعي \`collectSceneInputsFromDiskV2\` (بصمات ملفات المشهد وخطة الصوت) ثم \`probeSceneAvLockedV2\` مع \`ffprobe\` الحقيقي، ويتحقق من تطابق البايتات والبصمة وepoch والأبعاد والمدة والصوت المطلوب. يفك تشفير فيديوهي MP4 بالكامل باستخدام FFmpeg إلى مخرج null دون حفظ فيديو جديد.
- يرفض ثلاث حالات متعمدة: وصف الفيديو الصامت بأنه منطوق، وملف صوتي بلا فيديو، وملف بامتداد MP4 لا يحمل حاوية صحيحة.
- لا يستدعي صوت قرآن أو Quran Foundation أو تحويل تلاوات إلى TTS، ولا يفتح متصفحًا أو ينشر شيئًا.
- العملية منفصلة بصندوق مؤقت وهي تُنهي عمليات FFmpeg تحت سقف زمني قبل حذف مجلدها؛ تحقق من \`git status --short\` قبل/بعد تشغيلها.

## الأمر المطلوب على Mac

\`\`\`bash
STUDIO_FFMPEG_BIN=/opt/homebrew/bin/ffmpeg \
STUDIO_FFPROBE_BIN=/opt/homebrew/bin/ffprobe \
npx --no-install tsx tests/scene-real-av-smoke.ts
\`\`\`

شغّله داخل Worktree QA المعزول بعد \`npm run typecheck\` و\`npm run check\`. عند نجاحه تظهر سطور PASS للمشهدين الصحيحين ولحالات الرفض الثلاث، ثم سطر PASS نهائي. **لم يتم اختبار هذا الأمر على Mac بعد** في وقت كتابة التوثيق؛ لا ينسب له نجاح E1.

## الباقي قبل الإنتاج

هذا اختبار بنية **وفك تشفير ملف AV صناعي قابل للتشغيل**، وليس رندر Remotion لحلقة فعلية، ولا مشاهدة بشرية موثقة، ولا اختبار تحريك احترافي أو جودة المزج. كما أن القفل في الاختبار مجرد نطاق معزول بدون كُتّاب متنافسين، وليس حارسًا فعليًا لكل مسارات الكتابة. يجب بناء قفل موحد وإعداد Owner Session/CSRF، ومتحقق مشاهدة AV موثوق، وتكامل API/CLI/Queue/Render، ثم اختبار رندر المشهد الحقيقي على Mac قبل الدمج.

لا تغيير في \`main\` أو تسجيل اعتماد أو إرسال فيديو للإنتاج/النشر.
