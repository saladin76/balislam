# ٥. قواعد المحتوى والإخراج

القواعد المعتمدة لقناة «دفاتر الزمن» بمصدرها وتاريخها. القواعد العامة في `CLAUDE.md` تنطبق كلها ولا تُكرر هنا إلا بإشارة.
**«المشرف»** = صاحب القناة / المشرف الإبداعي. ما وُصف «مبدئيًا» لم يُعتمد نهائيًا.

## الأمانة التاريخية

| القاعدة | المصدر والتاريخ |
| --- | --- |
| التمييز بين الثابت، والرواية المختلف فيها («تذكر بعض الروايات…»)، واستنتاجنا | قالب السكريبت `templates/dafatir-alzaman/script.md` |
| كل معلومة في السكريبت مربوطة بمصدرها في `research.md` | `CLAUDE.md`، القاعدة الخامسة |
| لا تواريخ ولا أعمار ولا مواقع ولا أحداث لم يثبتها البحث؛ وما لا نعرفه يُقال بوضوح | المشرف، الأمران 011–012 (٥ نوفمبر)؛ `editorial-rebuild.md` |
| لا يُنسب أثر إلى آدم عليه السلام ولا ذريته الأولى | المشرف، الأمر 012 (٥ نوفمبر) |
| لا خريطة تحدد موضعًا لم يثبت (الهبوط، الجنة) | المشرف، الأمر 011 (٥ نوفمبر) |
| الرسوم التخطيطية (طبقات الأرض) فكرة لا موقع، ولا تُربط بحدث غيبي | `creative-direction.md` (٤ نوفمبر، والقاعدة باقية في الأوامر اللاحقة) |
| لا يُقدَّم مشهد مولَّد على أنه وثيقة تاريخية | `docs/motion-graphics-standards.md` (القسم التاسع عشر) |
| في الحلقات التاريخية: الحدود الجغرافية وفق الفترة، والأسماء والتواريخ صحيحة | المصدر نفسه |

## التجسيد والغيب

| القاعدة | المصدر والتاريخ |
| --- | --- |
| لا يُصوَّر نبي ولا صحابي؛ يُذكرون بالسرد فقط | `CLAUDE.md` (القنوات)؛ قالب السكريبت |
