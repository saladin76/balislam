**قالب الإدخال:**

```
## YYYY-MM-DD — الأمر NNN: العنوان
- المشكلة / الحاجة:
- ما تغيّر فعليًا:
- السبب:
- الملفات / المكونات:
- النطاق: عام لكل الحلقات / خاص بالحلقة NNN
- الاختبارات ونتائجها:
- الأثر على الأعمال السابقة:
- حالة الاعتماد:
- قيود / أعمال لاحقة:
```

البوابة ترفض دفع أي تغيير في ملفات المنظومة دون تحديث هذا الملف في الدفع نفسه ([04-technical.md](04-technical.md)).
