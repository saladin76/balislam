## ترتيب المراجع (لا مصدران للحقيقة)

1. **`CLAUDE.md`** في جذر المشروع: القواعد العامة الملزمة لكل القنوات. يتقدم على كل ما هنا.
2. **هذا الدليل**: خصوصيات «دفاتر الزمن» وحدها. لا ينسخ قواعد `CLAUDE.md`، بل يشير إليها ويضيف ما يخص القناة.
3. **ملفات الحلقة** (`channels/dafatir-alzaman/episodes/<الحلقة>/`): قرارات الحلقة نفسها، وسجل إنتاجها `production-log.md`.
4. **`docs/motion-graphics-standards.md`**: المعايير المهنية العامة للموشن جرافيك، وتتقدم عليها القواعد أعلاه.

## قاعدة التحديث الإلزامي

كل تعديل يؤثر في سلوك استوديو «دفاتر الزمن» أو أدواته أو قواعد إنتاجه، مهما صغر:

1. يُنفَّذ.
2. يُتحقق من نجاحه (اختبار، أو رندر يُنظر فيه).
3. يُحدَّث القسم المرتبط به في هذا الدليل.
4. يُضاف إدخال إلى [07-decisions.md](07-decisions.md).
5. يُذكر فيه: عام لكل الحلقات أم خاص بحلقة.
6. يُتأكد أن «دليل الاستوديو» في الواجهة يعرض النسخة الجديدة (يقرأ الملفات مباشرة، فيكفي حفظها).
7. لا تُعد المهمة مكتملة قبل ذلك.

**يُفرض آليًا:** بوابة التسليم ترفض دفع أي commit يغيّر ملفات منظومة القناة دون تحديث سجل القرارات في الدفع نفسه (`scripts/docs-sync.mjs`، انظر [04-technical.md](04-technical.md)).
