# هيكلة واجهة الاستوديو

تحديث ٦ نوفمبر ٢٠٢٦ يعيد تنظيم واجهة الاستخدام فقط. منطق المحرك، مسارات API، الحفظ التلقائي، تأكيد مغادرة النص غير المحفوظ، الاعتمادات، وترتيب الإنتاج تبقى في مكوناتها القائمة.

## خريطة التنقل

| المكان | المحتوى |
| --- | --- |
| القائمة الجانبية — مساحة العمل | الحلقات وغرفة العمليات، مكتبة الأصول والقوالب، المختبرات والمراجعات الفنية حين تتوفر للقناة |
| القائمة الجانبية — إدارة القناة | الهوية البصرية، إعدادات القناة، الاتصالات والمفاتيح |
| أسفل القائمة | دليل القناة حين يتوفر، وسياق الحلقة المفتوحة |
| الشريط العلوي | اسم القسم، القناة النشطة، واختيار الحلقة داخل مراحل الإنتاج |
| داخل الحلقة | مراحل البحث، السكريبت، الستوري بورد، الصوت، المشاهد، النشر بالشريط القائم نفسه |
| الرئيسية | عرض القناة الحالية أو غرفة عمليات كل القنوات، الإحصاءات، البحث والترتيب وبطاقات الحلقات |

القائمة الجانبية ثابتة على الشاشات الواسعة، وتفتح بزر «فتح قائمة التنقل» على الهاتف، وتغلق بزر الإغلاق أو بالنقر خارجها أو بمفتاح Escape. كل إجراء تنقل يحتفظ بفحص المغادرة والحفظ الذي كان مرتبطًا به. مفاتيح `localStorage` ومعرّفات الأقسام واختيار القناة والحلقة لم تتغير.

## حدود التغيير

- `app/src/ui/StudioSidebar.tsx` يعرض وجهات التنقل وسياق القناة والحلقة؛ لا يطلب بيانات ولا يحفظها ولا يكتب حالات اعتماد.
- `app/src/studio-shell.css` ينسق غلاف الواجهة والبطاقات والحقول والجداول فقط. هويات القنوات تبقى في ملفاتها ومزوّداتها، ومكونات رسم الفيديو لا تتغير.
- `app/src/App.tsx` يضع المكونات القائمة داخل الغلاف، ويعيد استخدام مسارات التنقل والحماية القائمة. لا مكوّن إنتاج جديد بديلًا عن البحث أو السكريبت أو المشاهد.
- دليل البداية المختصر يذكر موضع الأدوات الجديد.
- تظهر المختبرات والمراجعات الفنية والدليل بالشروط السابقة نفسها، ولا يُنقل أي سجل بينها.

الاختبار الوظيفي يشمل تبديل القنوات، فتح الحلقة ومراحلها، البحث والترتيب، الوصول لكل أداة، ورسالة مغادرة النص غير المحفوظ. لا يُستعمل أي اعتماد أو توليد صوت أو رندر مدفوع لمجرد اختبار الواجهة.
