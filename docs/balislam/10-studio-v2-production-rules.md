# قواعد الإنتاج — بالإسلام (Studio V2)

**المصدر:** `channels/balislam/channel.json`، `docs/balislam/01-constants.md`، مرجعيات القناة المعتمدة، `CLAUDE.md`. **حالة الدمج:** مرشح اختبار، لا تغيير للحلقة 001.

## هوية القناة ووظيفتها

- قضايا النفس والأسرة والمال والعلم من منظور إسلامي، بعيدًا عن الوعظ الإنشائي وتزيين الحركة لمجرد الحركة.
- «محراب النور» والافتتاحية والشعار والخطوط المعتمدة ثابتة. **بلا وجوه وبلا موسيقى**. يمكن استعمال الآيات والأحاديث بضوابط الاستشهاد.
- نبرة الراوي وقورة وهادئة، والسكوت المقصود عند الآية والذكر مسموح ولا يُعالج بزخرفة بصرية.
- كل رسمة أو لقطة تشرح معنى الجملة فعلًا؛ عند عدم وجود عنصر مطابق لا يوضع عنصر تقريبي.

## تطبيق الخطوات الخمس

1. **إعداد الحلقة:** تحديد السؤال والجمهور، البحث والسكريبت، مراجعة الحقائق والآيات والأحاديث، التشكيل؛ المصادر الشرعية يراجعها صاحب المشروع أو مختص مؤهل.
2. **Storyboard PDF:** سيناريو بصري لكل مشهد، مواضع السكوت، الكاميرا والإضاءة وهوية القناة، والنصوص الأصلية. لا تلصق رموزًا أو زخارف ملاصقة للآية.
3. **المشاهد:** السرد العادي ينتجه نظام الفويس أوفر بعد تحديد النبرة. التلاوة البشرية يرفعها المالك إلى Claude وتُربط بالنص والمرجع وحقوق الملف. إنتاج ومراجعة AV للمشهد الحالي، تصحيحه واعتماده، ثم المشهد التالي.
4. **مراجعة الحلقة:** الدقة الشرعية، انسيابية الحركات، وضوح الآيات والتشكيل، توافق الصوت والصورة، هوامش الهاتف، ونسبة الحركة مع استثناءات التوقير المعتمدة.
5. **Master والنشر:** ملف معتمد كامل ومطابق البصمة، لا صوت قرآني TTS، ولا فيديو قبل المشاهدة 1×.

**فحوص آلية مستهدفة:** منع القوالب والعناصر المستبعدة من المكتبة؛ منع معرّف مؤثر موسيقي صريح؛ منع بطاقة آية بنص مؤقت؛ رفض تلاوة غير مرفوعة ومعتمدة؛ بطلان اعتماد مشهد بعد تعديل مدخلاته.

**بشري حصري:** سلامة الاستدلال الشرعي، جواز تصوير فكرة، جودة التمثيل، نبرة الراوي، اختيار الحركة وإيقاع الصمت، حقوق التسجيل.
