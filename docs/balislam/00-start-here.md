هذه الصفحة تكفي لتبدأ دون الرجوع إلى أي محادثة سابقة. كل ما فيها مأخوذ من الكود الحالي.

5. الصفحة التي تخص مهمتك: [02-architecture.md](02-architecture.md) أو [03-engine.md](03-engine.md) أو [04-render-quality.md](04-render-quality.md).
6. [05-development.md](05-development.md) قبل أول تعديل، وآخر إدخالات [06-decisions.md](06-decisions.md) لتعرف أين توقف العمل.

## ٢. نطاق العمل

- القناة: `balislam`. أوامر الأداة: `npx bal -c balislam …` (أو `BAL_CHANNEL=balislam`).
- الكود مشترك بين القنوات الثلاث في مواضع كثيرة (`src/plan/`، `src/remotion/scenes/Episode.tsx`، `app/`). أي تغيير فيها يجب أن يبقى أثره محصورًا في «بالإسلام»: بحقل اختياري، أو بقناة صريحة في سجل الأدوات (`channels` في `src/plan/engine.ts`)، أو بقوالب مكتبتها وحدها (`templateMeta` في `src/plan/templateMeta.ts`).
- لا تغيّر هوية قناة أخرى ولا إعداداتها ولا أدلتها (`docs/dafatir-alzaman/`، `docs/zubdat-alkutub/`).

## ترتيب إنتاج الحلقة (قرار صاحب المشروع، ٦ نوفمبر ٢٠٢٦)

المرجع الرسمي ملف studio-voice-first-production-contract.md في مجلد docs على الفرع `feat/studio-storyboard-tone-voice-first` (لم يُدمج في main بعد، فلا يوجد في هذا الفرع). يُتَّبع يدويًا الآن، ولا يُدّعى أن بوابات لم تُنفَّذ في الكود صارت تعمل:

0. السكريبت والمصادر موثَّقة (`bal check`، `bal review`).
1. **ستوري بورد مرئي للحلقة كاملة** قبل أي صوت أو فيديو حركي كامل: `npx bal -c balislam storyboard-board <الحلقة> --version vN` (لقطات ثابتة من المحرك، PDF، ورقة لكل فصل، بيان بالبصمات). مراجعته ثم اعتماده صراحة في `storyboard.json` (زر الاستوديو)؛ نجاح الاختبارات أو الرفع ليس اعتمادًا.
2. خريطة النبرة لكل مقطع منطوق (`tone` في المشهد، ومقاطع داخلية موثَّقة إن تغيّر الإحساس) قبل التوليد.
3. عينات الصوت ثم التعليق الكامل، والاستماع إليه متصلًا، وقرار **VOICE_APPROVED_FOR_VIDEO** (تحريري، لا تضعه الأداة).
4. الفيديو على توقيت الكلمات المسجلة فعلًا، ومراجعته بالصوت والصورة معًا.
5. المراجعة الشاملة، ثم Master لا يُصنع إلا بموافقة صاحب المشروع على الملف نفسه.

المطبَّق في الكود الآن: منع الصوت والنسخة النهائية قبل اعتماد الستوري بورد ببصمة كل مشهد (`src/plan/storyboard.ts`)، ومنع اعتماده وفيه آية بلا نص. غير المطبَّق: إلزام النبرة لكل مقطع، وسجل اعتماد الصوت قبل المعاينة، والتسليم الآلي إلى Drive.
التسليم إلى Drive: من جلسة سحابية بلا جهاز Mac تُوضع الملفات في فرع الطابور `studio-handoff-queue` بوظيفة لكل ملف (ملف studio-agent-handoff-contract.md على الفرع نفسه)، والحالة `PENDING_TRANSFER` حتى يعيد الجسر على الـMac `DELIVERED` برابط موثَّق.

## ٣. التشغيل

```bash
npm install                  # يفعّل بوابة التسليم (.githooks/pre-push)
npm run app                  # الاستوديو على http://localhost:4321
npx tsc --noEmit -p .        # الأنواع
npx vitest run               # كل الاختبارات
npm run gate                 # الاثنان معًا كما تفحصهما البوابة
```

في بيئة بلا إنترنت لمتصفح Remotion يُمرَّر متصفح محلي: `REMOTION_BROWSER_EXECUTABLE=<المسار>` (قبل تشغيل الاستوديو أيضًا، وإلا تفشل مهام الرندر فيه بمحاولة تنزيل المتصفح).

## ٤. ممنوع دون موافقة صاحب القناة

- تغيير الهوية أو الألوان أو الخطوط أو الافتتاحية (`brand/identity/approved.ts`، و`tests/identity-approved.test.ts` يقفلها).
- جعل أي أداة افتراضية للحلقات الجديدة، أو اعتبارها معتمدة فنيًا (الاعتماد زر في الاستوديو، لا قرار برمجي).
- تغيير خطة حلقة قائمة أو فيديو معتمد، أو حذف معاينات أو نسخ سابقة.
- كتابة سكريبت أو بدء إنتاج حلقة أو توليد صوت أو تلاوة، ما لم يُطلب صراحة.
- أي مسألة شرعية أو تحريرية (النص والتشكيل، الاستشهادات، الآيات والأحاديث والأذكار): المرجع وثائق `channels/balislam/references/` وصاحب القناة، لا الكود.
- تعطيل اختبار أو تجاوز البوابة (`--no-verify`).

## ٥. متى تكتمل المهمة

- الكود يعمل في مسار الإنتاج الحقيقي (لا في المختبر وحده)، ومتاح من محرر المشهد إن كان أداة إخراجية.
- `npx tsc --noEmit -p .` و`npx vitest run` ناجحان، وأي ميزة بصرية رُندرت فعلًا وفُحصت لقطاتها.
- الحلقات القديمة لم تتغير (طريقة التحقق في [05-development.md](05-development.md#٨-التحقق-من-التوافق-مع-الإنتاج-السابق)).
- المعاينة مرفوعة إلى الاستوديو بعنوان يذكر حالتها («جاهز للمراجعة · لم يُعتمد فنيًا»).
- المرجع محدَّث وإدخال في [06-decisions.md](06-decisions.md)، ثم الدفع عبر البوابة.

نجاح الاختبارات لا يعني اعتمادًا فنيًا. الاعتماد قرار صاحب القناة وحده.



## التنقل في واجهة الاستوديو الجديدة — ٦ نوفمبر ٢٠٢٦

الأقسام العامة متاحة من القائمة الجانبية: الحلقات وغرفة العمليات، المكتبة، المختبرات والمراجعات الفنية حين تتوفر. إدارة القناة تضم الهوية والإعدادات والاتصالات، والدليل في أسفل القائمة. مراحل الإنتاج داخل الحلقة تبقى بالشريط نفسه. على الهاتف افتح القائمة من زر التنقل. راجع `docs/studio-interface.md`. هذا تنظيم للعرض فقط؛ لا تغيير في قواعد القناة أو سير اعتمادها أو محتواها.
