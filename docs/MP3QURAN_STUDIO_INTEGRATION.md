# MP3Quran — استعراض صوتي اختياري في استوديو القنوات الثلاث

الحالة: **دمج تجريبي للتصفح والاستماع فقط**؛ ليس مصدرًا افتراضيًا للرندر ولا ترخيصًا للنشر.

## المرجع
رابط المستخدم: https://mp3quran.net/ar/api/2 (إصدار قديم)
التوثيق الحالي: https://www.mp3quran.net/ar/api
مسارات API v3 المستخدمة:
- `GET https://www.mp3quran.net/api/v3/reciters?language=ar`
- `GET https://www.mp3quran.net/api/v3/suwar?language=ar`
- مصدر MP3 للمعاينة: `{moshaf.server}{surah3}.mp3` حيث `surah3` رقم السورة مكوّن من ثلاث خانات (مثل 018).

## حدود العمل
- في «صوت الحلقة» لكل قناة يظهر زر **فتح المكتبة لهذه القناة مؤقتًا**. لا تُستدعى الخدمة قبل ضغط المستخدم عليه.
- المستعرض يتيح اختيار القارئ والرواية/المصحف والسورة والاستماع عبر عنصر `audio`، ولا يكتب في `plan.json` أو `recitations/index.json` أو ملفات الصوت.
- إغلاق المستعرض أو تبديل القناة يلغي رابط الاستماع المفتوح ويعيد حالة التفعيل إلى الإغلاق. حالة التفعيل غير محفوظة، لكيلا تنتقل بين القنوات.
- يظل Quran Foundation مستقلًا ومصدره واختياراته غير متغيرة.
- جانب الخادم يقدم `/api/mp3quran/reciters`, `/api/mp3quran/suwar` و`/api/mp3quran/preview?reciter=…&moshaf=…&surah=…` كطلبات GET فقط.
- يرفض روابط الصوت غير HTTPS أو غير الصادرة من `serverN.mp3quran.net`. لا يوجد proxy ولا تنزيل آلي.
- لا يقدّم النظام اقتطاع آيات من ملف سورة كاملة؛ يجب عدم الادعاء بأن اختيار سورة يعادل دقة التوقيت على مستوى الآية.

## حقوق الاستخدام
الوصول العام للـ API لا يثبت حق إعادة استخدام التسجيلات في فيديو تجاري أو إعادة توزيعها. تُعرض التلاوة للمعاينة فقط. لا يسمح هذا التنفيذ بإضافتها إلى الفيديو أو حزمة النشر. يتطلب توسيع ذلك إثبات الإذن وشروط النسبة والتخزين والتحويل لكل تلاوة/قارئ.

## بوابة الجودة قبل الدمج
1. نجاح `npm run check` واختبارات تصفية بيانات MP3Quran.
2. تشغيل `npm run app` والتأكد من ظهور المستعرض في «صوت الحلقة» لكل قناة على حدة.
3. اختبار الاستجابة مع بيانات فعلية من الخدمة؛ التوافر يعتمد على الموقع واتصال Mac.
4. التأكد من أن إغلاق المستعرض وإعادة اختيار قناة لا يغيّران ملفات الحلقات.
5. التأكد من أن Quran Foundation والتسجيلات السابقة تعمل دون تغير.

لا تُعد نجاحة اختبارات الموك دليلاً على توافر الشبكة الخارجية أو أذونات النشر.
