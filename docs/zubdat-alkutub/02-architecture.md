# البنية التقنية للاستوديو

يوثّق هذا القسم ما هو موجود فعلًا في المستودع. وكل مسار مذكور هنا يتحقق من وجوده `tests/zubdat-reference.test.ts`.

## ملفات القناة

```
channels/zubdat-alkutub/
├── AGENTS.md                 نقطة الدخول المختصرة للمطور أو الوكيل
├── channel.json              الاسم والمجالات والقواعد والجدول وطبقة الصوت والخاتمة والمستبعدات
├── identity.json             الثيمات والألوان والخطوط وأحجام النص (identity.default.json الأصل)
├── pronunciation.json        قاموس النطق للقناة (فارغ حاليًا)
└── episodes/NNN-slug/        حلقة لكل مجلد
```

المرجع الدائم نفسه في `docs/zubdat-alkutub/` (على نظام أدلة القنوات المشترك)، ويظهر في الاستوديو باسم «مرجع الاستوديو».

قالبا الحلقة الجديدة: `templates/zubdat-alkutub/script.md` و`templates/zubdat-alkutub/research.md`.

## مجلد الحلقة (مثال: `episodes/001-awwal-marra-osalli/`)

| الملف | دوره | في Git؟ |
|---|---|---|
| `script.md` | السكريبت المشكول بفصوله ومشاهده، وقسم الاستشهادات | نعم |
| `tashkeel.md` | نسخة النطق المشكولة (يقرؤها مدقق التشكيل) | نعم |
| `research.md` | ملف الدراسة: كل معلومة في السكريبت ومصدرها وصفحتها | نعم |
| `plan.json` | خطة المشاهد: القالب والنص والحقول (`shot`، `labels`، `cues`…) لكل مشهد | نعم |
| `review.json` | سجل التوثيق: قرار كل استشهاد، مربوط بنصه | نعم |
| `storyboard.json` | اعتماد لقطة كل مشهد قبل الصوت، مربوط ببصمة المشهد | لا: حالة محلية مربوطة بالسجل الموقَّع على جهاز المالك (D60) |
| `scene-review.json` | مراجعة كل مشهد بعد تنفيذه | نعم، حين يوجد (لم يُنشأ للحلقة 001 بعد) |
| `docs/` | مستندات إخراج الحلقة (الرؤية، الصوت، المؤثرات، المصادر) | نعم |
| `reviews/` | تقارير المراجعة HTML (تظهر في «ملفات المراجعة» في الستوري بورد) | نعم |
| `previews/` + `index.json` | معاينات الاستوديو: خانة لكل موضوع، والعنوان والملاحظة في الفهرس | نعم |
| `quran.json` | نصوص الآيات من Quran Foundation | **لا** (شروطهم) |
| `voice/`، `out/`، `recitations/`، `status.json` | الصوت والرندر والتلاوات وحالة الاعتماد | **لا** (على الجهاز) |

## أجزاء المنظومة ودور كل جزء

### خاص بزبدة الكتب

| الجزء | الدور |
|---|---|
| `src/remotion/zubdat/inkKit.tsx` | عُدّة الحبر: الورق، والخط بالقلم (`Stroke`)، والكتابة لحظة النطق (`Write`)، والتظليل (`Mark`)، والشطب (`Cross`)، والسهم، والبطاقة، والإنسان بلا ملامح، والأيقونات. وفيها `makeAt` و`makeEnd` لربط كل حدث بلحظة كلمته |
| `src/remotion/zubdat/shots.tsx` و`shots2.tsx` | اللقطات المصمَّمة للحلقة 001 (معالجة خاصة)، وسجل `INK_SHOTS` الذي يجمع كل المشاهد |
| `src/remotion/zubdat/kitShots.tsx` | الأدوات العامة `kit-*` القابلة للتخصيص لكل كتاب |
| `src/remotion/scenes/InkShot.tsx` | قالب «مشهد حبر مصمَّم». يلتزم بما يلي: الكاميرا لا تقص عنصرًا ظهر، والمنطقة الآمنة (`SAFE`)، وسكون الكاميرا عند ذكر الله، وقلب الصفحة بين الأفكار |
| `src/studio/zubdat.ts` و`zubdatSheet.ts` | جدول المعايير (`STANDARDS`) وفحوص الاستوديو وتقاريره (`npx bal zubdat …`) |
| `src/quran/audit.ts` | تقرير أدلة الآيات ومقابلتها بالمرجع (`npx bal quran-compare`). بُني للحلقة 001 ويعمل لأي حلقة |

قالب `ink-shot` مقصور على هذه القناة في `src/plan/templateMeta.ts` (`only: ["zubdat-alkutub"]`).

### مشترك بين القنوات (يُستعمل ولا يُغيَّر لأجل هذه القناة وحدها)

| الجزء | الدور |
|---|---|
| `src/script/` | تحليل السكريبت وفحصه، وسجل التوثيق (`review.ts`) |
| `src/plan/` | القوالب وحقولها (`templates.ts`)، والمدد (`duration.ts`)، والستوري بورد (`storyboard.ts`)، ومراجعة المشاهد (`sceneReview.ts`) |
| `src/voice/` | توليد الصوت وتوقيت الكلمات، ومدقق التشكيل (`tashkeelReport.ts`) |
| `src/quran/` | جلب الآيات (`client.ts`) |
| `src/render/` | الرندر (`episode.ts`)، ومقياس الحركة (`motionMeter.ts`)، والسكون المقصود (`stillness.ts`)، والمعاينات (`episodePreviews.ts`)، والجودة (`quality.ts`) |
| `src/package/` | حزمة النشر وفحص الآثار (`traces.ts`) |

| `config.json` | إعدادات الفيديو والجودة والصوت العامة |

## مصادر البيانات والإعدادات

- **هوية القناة وقواعدها:** `channel.json` و`identity.json`.
- **نص الحلقة:** `script.md`، والخطة `plan.json` تُولَّد منه بالأمر `npx bal plan`، وتُحفظ التعديلات اليدوية على الخطة.
- **نص الآيات:** `quran.json` من Quran Foundation (الرسم العثماني)، ولا يُكتب نص الآية في `plan.json`. البيئة الإنتاجية تحتاج `QF_ENV=production`، وإلا فالعميل على بيئة `prelive`.
- **توقيت الكلمات:**
  - بعد الصوت: من محاذاة الصوت الفعلية.
  - قبله: توقيت تقديري (`estimateTimings`) حتى يُعاد الحساب على الصوت.
  - مدة المشهد الصامت: `words/130×60 + 1.2` ثانية. والمشهد بصوت: مدة الصوت + 0.35 ثانية. والحد الأدنى لمشهد الحبر 4 ثوانٍ.
- **الأسرار:** `.env` على جهاز صاحب القناة فقط، وتُذكر بأسمائها: `QF_CLIENT_ID` و`QF_CLIENT_SECRET` و`QF_ENV` ومفاتيح ElevenLabs.

## العلاقة بين السكريبت والمشاهد والصوت والمعاينات والنهائي

```
research.md → script.md (+ tashkeel.md، review.json) → plan.json (مشهد لكل فقرة: template + props)
   → رندر صامت 1080p → previews/ في الاستوديو → storyboard.json (اعتماد اللقطات)
   → صوت الراوي (voice/) + تلاوة مرخّصة → رندر بصوت → scene-review.json (مراجعة كل مشهد)
   → النسخة الأساسية 4K → اعتماد «النسخة الأساسية» → الشورتس → package (حزمة النشر)
```

شروط الانتقال بين كل مرحلة وأخرى في [قواعد إنشاء الحلقات](03-workflow.md).

## التغيير دون المساس بالقنوات الأخرى

- **ما يخص القناة** يوضع في `src/remotion/zubdat/` و`src/studio/` وملفات `channels/zubdat-alkutub/`.
- **الحماية القائمة:**
  - `templateMeta` يقصر القالب على القناة.
  - `assertZubdat()` يرفض تشغيل أدوات الاستوديو على قناة أخرى.
  - `library.exclude` خاص بالقناة.
  - اختبار الهويات المعتمدة يمنع تسرب بصمة قناة إلى أخرى.
- **ما يمس المشترك** (المقياس، القوالب العامة، `config.json`، الهويات) يُفصل في مهمة مستقلة بموافقة صاحب المشروع، ولا يُدمج في عمل القناة.
- **بصمة الرندر:** أي ملف تحت `src/remotion/` يغيّرها لكل القنوات، فتظهر تقارير الحركة السابقة بوصف «قديمة». هذا أثر متوقع ولا يغيّر سلوكًا، ويُذكر في التقرير.
- **بوابة الدفع:** `git push` يعيد فحص الأنواع والاختبارات كلها على نسخة نظيفة قبل القبول.
