# المرجع الدائم لاستوديو زبدة الكتب — الهندسة والإنتاج ومعايير التطوير

هذا المرجع خاص بقناة «زبدة الكتب» (`zubdat-alkutub`) وحدها، ولا يحكم القنوات الأخرى.

- **مكان ظهوره:** يظهر في الاستوديو بعد اختيار القناة، من «إدارة الاستوديو ← مرجع الاستوديو».
- **مصدره:** المجلد `docs/zubdat-alkutub/` في المستودع، وفهرسه `docs/zubdat-alkutub/guide.json`، على نظام أدلة القنوات المشترك. ما يُعرض في الاستوديو هو هذه الملفات نفسها، فتاريخ تعديلاتها هو تاريخ Git. وكل صفحة جديدة تُضاف إلى `guide.json` وإلى الفهرس أدناه.
- **نقطة الدخول المختصرة** للمطور أو الوكيل: `channels/zubdat-alkutub/AGENTS.md`.

## حالات كل قرار أو قدرة

تُميَّز في كل الأقسام بين أربع حالات:

- **مقترح:** فكرة أو خطة لم تُنفَّذ. لا تُعامَل قدرةً موجودة.
- **منفّذ:** موجود في الكود أو الملفات.
- **مختبر:** نُفّذ وجرى عليه اختبار فعلي، وتُذكر نتيجته.
- **معتمد:** وافق عليه صاحب القناة أو الإشراف الفني (إبداعيًا أو تحريريًا)، أو المراجع المؤهل (شرعيًا). كل نوع من الاعتماد مستقل عن غيره.

نجاح الاختبارات البرمجية لا يعني اعتمادًا فنيًا ولا تحريريًا ولا شرعيًا.

## قواعد الحوكمة

- لا يُغيَّر معيار إبداعي معتمد دون موافقة الإشراف الفني.
- لا يُسجَّل مقترح على أنه قدرة منفّذة، ولا تُسجَّل نتيجة اختبار لم يُجرَ.
- لا يُخلط الاعتماد التحريري بالاعتماد الشرعي.
- لا تُكتب في المرجع كلمة مرور ولا مفتاح ولا أي بيانات سرية. تُذكر أسماء المتغيرات فقط (مثل `QF_CLIENT_ID`)، وقيمها في `.env` على جهاز صاحب القناة.
- لا تُستبدل نسخة إنتاجية سابقة لمجرد تحديث الوثائق.
- نطاق المرجع «زبدة الكتب» وحدها. وما يمس جزءًا مشتركًا من المحرك يُفصل عنه ويحتاج موافقة مستقلة (انظر [البنية](02-architecture.md)).

## قاعدة التحديث الإلزامي

**لا تكتمل مهمة تطوير في استوديو «زبدة الكتب» حتى يُحدَّث المرجع المرتبط بها.** عند كل إضافة أو تعديل أو إصلاح أو تغيير قرار:

1. حدّث القسم المعني.
2. سجّل في [سجل القرارات](06-decisions.md) ما تغير ولماذا، ونطاقه، ومكانه، ونتيجة اختباره.
3. أضف سطرًا إلى [سجل تعديلات المرجع](CHANGELOG.md) بالتاريخ ومرجع الـcommit.
4. شغّل `npx vitest run tests/zubdat-reference.test.ts`. يفشل هذا الاختبار في الحالات الآتية:
   - مسار مذكور في المرجع لم يعد موجودًا.
   - معيار من جدول `STANDARDS` غائب عن [المعايير](05-quality.md).
   - أداة `kit-*` أو أمر `zubdat` غير موثق.
   - رابط داخلي مكسور.
   - نص يشبه مفتاحًا سريًا.

وبوابة الدفع (`scripts/docs-sync.mjs`) ترفض أي تغيير في منظومة القناة لا يصاحبه تحديث `docs/zubdat-alkutub/06-decisions.md`. المنظومة هي:

- `src/remotion/zubdat/`.
- `InkShot.tsx`.
- `src/studio/`.
- ملفات هوية القناة وإعداداتها.
- `templates/zubdat-alkutub/`.

والإصلاح الصغير يُسجَّل بما يهم المطور التالي فقط، بلا حشو.
