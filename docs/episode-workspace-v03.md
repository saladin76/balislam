# مساحة الحلقة الموحدة — مراجعة الإصدار 0.3

هذه واجهة تنظيمية فوق المحرك القائم، وليست صيغة إنتاج أو مصدر اعتماد جديدًا.

## ما تغير

- مراحل مستقلة: **البحث ← السكريبت ← الستوري بورد ← الصوت ← المشاهد ← النشر**.
- شريط يقرأ حالة العمل من سجلات الاعتماد والصوت والنشر الموجودة.
- لوحة ملاحظات تقود إلى سطر السكريبت أو المشهد المرتبط بالمشكلة.
- شاشة صوت مستقلة تستعمل `VoiceBox` الأصلي وتعرض حالة المقاطع.
- لوحة إعدادات مشهد أخف، مع إبقاء التراكبات والمؤثرات في قسم متقدم قابل للفتح.
- حماية ملف البحث من ضياع التعديلات عند مغادرة المحرر أو تحديث الاستوديو.

لم تتغير `src/plan` أو `src/voice` أو `src/render` أو ملفات الحلقة، ولم تُضف واجهات API.

## اختبار يدوي مطلوب على الجهاز المحلي

1. شغّل `npm run app` على الفرع `feat/episode-workspace-v03`.
2. افتح حلقة من كل قناة. تأكد أن العنوان والقناة والملاحظات تخص الحلقة الصحيحة.
3. حرّر ملف البحث دون حفظ. انتقل إلى مرحلة أخرى: يجب ظهور تحذير، وإلغاء المغادرة يجب أن يبقي النص.
4. احفظ البحث والسكريبت. انتقل بين المراحل الست، ثم عد إلى النص وتأكد من بقاء التعديلات.
5. أضف خطأ سكريبت له رقم سطر، واضغط عليه من لوحة الملاحظات: ينبغي الانتقال للسطر الصحيح.
6. افتح الستوري بورد واختر بطاقة: يجب فتح **المشهد المختار نفسه** في محرر المشاهد.
7. غيّر عنصرًا بصريًا في مشهد معتمد: يجب أن تعود حالة اعتماده إلى المراجعة وفق المنطق القائم.
8. افتح الصوت، راجع المقاطع الجاهزة والقديمة والمفقودة، وانتقل من أحدها إلى المشهد الصحيح.
9. تحقق من الحفظ التلقائي للمشهد ثم غيّر القناة والحلقة دون ظهور بيانات القناة السابقة.
10. اختبر شاشات عريضة وضيقة؛ لا ينبغي اختفاء أدوات المعاينة أو الحفظ.
11. تحقق من أن النسخة النهائية والشورتس لا تُنتج قبل بوابات الجودة الأصلية.
12. انشر فقط من حزمة معتمدة؛ تذكّر أن حالة `published` تُسجَّل من مرحلة النشر نفسها.

## الفحص الآلي

```bash
npm ci
npm run typecheck
npm test
```

يُفضَّل اختبار رندر قصير لحلقة موجودة ومقارنة مخرجاته قبل وبعد التغيير. نجاح TypeScript وVitest لا يغني عن تجربة الواجهة بصريًا، أو سماع الصوت، أو مشاهدة النسخة النهائية.

## نطاق غير مشمول

لا يتضمن هذا التعديل محرر مونتاج كاملًا، ولا نظامًا جديدًا لتوليد المشاهد، ولا تعديلًا لسلوك بوابات الاعتماد. يظل تحسين جودة الإخراج الفعلي مسارًا منفصلًا عن تبسيط الواجهة.
