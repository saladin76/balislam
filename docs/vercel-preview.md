# نسخة الاستوديو المنشورة للمعاينة

النشر على Vercel يعرض نسخة للقراءة فقط، وليس خادم إنتاج. لا تُغيّر هذه النسخة حالات اعتماد المشاهد أو الحلقات، ولا تنفّذ الصوت أو التلاوة أو الرندر أو التحديث أو الحذف أو الحفظ.

## البناء

- Root Directory: جذر المستودع.
- Build Command: `npm run build` (أو `npx vite build --config app/vite.config.ts`).
- Output Directory: `app/dist`.
- Install Command: `npm ci`.
- `VERCEL=1` يفعّل نسخة المعاينة تلقائيًا. للاختبار المحلي: `BAL_STUDIO_PREVIEW=1 npm run build`.

أثناء البناء تُقرأ بيانات القنوات والحلقات والهويات والمختبرات والدليل من الملفات الموجودة في هذه النسخة من المستودع، من قائمة GET محددة فقط، وتُكتب في `studio-preview.json`. تُرفق فيديوهات MP4 المسجلة في معاينات الحلقات والمختبرات إذا كانت موجودة في المستودع. لا تُنسخ ملفات الجهاز المحلية أو المخرجات غير المرفوعة.

لا يُقرأ `.env` في وضع المعاينة، ولا تُصدّر إعدادات الاتصال أو قيم المفاتيح. صفحة الاتصالات تعرض شرحًا فقط. لا تضف مفاتيح خدمات مدفوعة إلى إعدادات هذه المعاينة.

## الحدود

- التحديثات تظهر بعد إعادة البناء والنشر؛ ليست مزامنة حية مع جهاز المنتج.
- يمكن تبديل القنوات وقراءة بيانات الحلقات ومشاهدة المعاينات المرفوعة. الخدمات التي تحتاج الخادم تعرض رسالة توضح أنها محلية.
- التعديلات في حقول الواجهة لا تُحفظ، وكل طلب غير GET مرفوض قبل أي اتصال بالخادم.
- ملفات الصوت والأصول المحلية غير المرفوعة إلى GitHub لن تعمل في مشغل المشاهد أو التنزيلات؛ المعاينات المرفوعة هي وسيلة المراجعة على الويب.
- فشل تحميل بيانات الهوية يعرض خطأ مع إعادة المحاولة، بدل شاشة تحميل دائمة.
- بيانات المعاينة متاحة لمن يستطيع زيارة النشر؛ لا ترفع ملفات خاصة إضافية أو أسرارًا إلى المستودع أو مجلدات المعاينة.

التشغيل المعتاد بـ`npm run app` يحتفظ بالخادم المحلي وسير العمل الأصلي. الاستضافة الكاملة للحفظ والإنتاج تحتاج خادمًا وتخزينًا دائمًا وتصميم صلاحيات منفصلًا.
