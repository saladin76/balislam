# AlQuran Cloud — مكتبة قراءة ومعاينة صوت الآية

الحالة: **معتمد بدل MP3Quran في واجهة استوديوهات القنوات الثلاث**.

- المصدر: https://alquran.cloud/api
- شروط الاستخدام: https://alquran.cloud/terms-and-conditions
- القائمة: `GET /api/alquran-cloud/editions` لطبعات الصوت العربية.
- المعاينة: `GET /api/alquran-cloud/ayah?surah=1&ayah=1&edition=ar.alafasy` تعيد النص العثماني والتلاوة للآية المحددة.
- حُذفت واجهة ومحول ومسارات واختبارات MP3Quran.
- الاستوديو لا يحمّل الصوت ولا يغيّر خطط الحلقات أو فهرس التلاوات. لكل قناة حالة تصفح مستقلة.
- يُتحقق من مرجع السورة والآية في استجابتي النص والصوت ومن أن رابط MP3 مشفر HTTPS ومن نطاق CDN المعتمد.
- لا يحتاج API إلى مفتاح اتصال للمسارات العامة، ويتطلب إنترنت.

## حقوق التسجيلات والاعتماد الإنتاجي
التلاوات مرخّصة للخدمة للاستخدام غير التجاري؛ لا تُمنح تلقائيًا حقوق إعادة استخدامها تجاريًا على يوتيوب. لذلك يتضمن JSON العلمين `rightsVerified: false` و`publicationAllowed: false`؛ لا يمكن تحويل المعاينة إلى مصدر تلقائي للرندر أو النشر دون ترخيص مناسب. يبقى مزود التلاوة الإنتاجي السابق وملفاته كما هي حتى يُعتمد مسار حقوق وتدقيق مستقل.
