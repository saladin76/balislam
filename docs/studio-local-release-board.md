# Studio — لوحة جاهزية النشر المحلية

هذه الإضافة في PR تطوير مستقل، ولا تُغير نسخة localhost:4321 أو تضيف أي نشر تلقائي.

## أين تظهر؟
في «مركز التسليمات» تظهر الآن «جاهزية الحلقة 001 للنشر» لثلاث قنوات، بجانب قائمة ملفات Drive الموجودة.

- مصدر التقرير: ملفات القناة داخل **Git worktree الذي يشغّل Studio الحالي فقط**. لا يتم فحص 24 worktree، ولا اختيار نسخة تلقائيًا.
- تفحص: صحة السكريبت، اعتماد Storyboard ببصمات المشاهد، مراجعة المشاهد الحالية، الاستشهادات الموثقة، بطاقات الآيات الناقصة، التعليق الصوتي المطابق، وجود Master موثّق بالصوت، اعتماد المالك المرتبط بملف Master، وأصول النشر.
- نتيجة «غير جاهز» تعرض كل العوائق. نتيجة «يحتاج مشاهدة واعتمادًا بشريًا» **ليست ترخيصًا للنشر**، حتى لو اكتملت كل مؤشرات الملفات.
- زر «فتح الحلقة للمراجعة» لا يكتب أو يرفع أو يعتمد شيئًا.
- زر «تحديث» يعيد القراءة فقط من Mac؛ التطبيق لا يولّد خططًا أو صوتًا أو فيديو في هذا المسار.
- لا يمنح التقرير اعتمادًا عند مشاهدة لقطات مختارة فقط. مراجعة الفيلم كاملًا 1× وحقوق المواد لازمتان دائمًا.

## اختبار Mac المعزول

```bash
cd "$HOME/balislam"
git fetch origin feat/studio-local-release-board-20261106
bash <(git show origin/feat/studio-local-release-board-20261106:scripts/studio-terminal-preview.sh) check
```

بعد نجاح `CHECK_OK` وإغلاق أي خادم سابق على 4322:

```bash
cd "$HOME/balislam"
bash <(git show origin/feat/studio-local-release-board-20261106:scripts/studio-terminal-preview.sh) serve
```

افتح `http://127.0.0.1:4322` ثم «مركز التسليمات»، وتحقق من القنوات الثلاث. إذا ظهر خطأ في قراءة قناة، سيُعرض خطأ تلك القناة دون طمس نتائج القناتين الأخريين.

**لا تستخدم** `fresh-start.command` أو `git reset --hard` ولا تدمج هذا الفرع في main قبل اختبار Mac واعتماد واجهة المراجعة.
