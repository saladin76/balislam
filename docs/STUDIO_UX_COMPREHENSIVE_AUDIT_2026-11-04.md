# تدقيق تجربة العمل في الاستوديو — النسخة الأولى
التاريخ: 2026-11-04
النطاق: استوديو القنوات الثلاث، واجهة Vite/React، واجهات API المحلية، مسار إنتاج الحلقة وإعدادات الاتصال والتحديث.
المرجع: قراءة مباشرة لملفات `app/src/App.tsx` و`app/src/tabs/{HomeTab,OpsRoom,EpisodeTab,SettingsTab,ChannelTab}.tsx` و`app/src/workspace/{EpisodeWorkspaceBar,VoiceWorkspaceTab}.tsx` و`app/server/{api,extra,update}.ts` و`src/settings/env.ts` و`src/render/{storyboardMotion,motionFingerprint,motionValidity}.ts`.
الحدود: هذا تدقيق شيفرة وتحسين أولي للتجربة؛ **لا يثبت** نجاح تجربة استخدام بشرية كاملة على جهاز Mac أو أن جميع عمليات الرندر تعمل، ولا يغيّر قرارات الإخراج أو محتوى القنوات.

## 1. الخلاصة التنفيذية
**المشكلة ليست نقص الأدوات بل تزاحم مساراتها وتعرّض المستخدم للتفاصيل التشغيلية قبل الحاجة إليها.**
كان الرأس يعرض أربع وجهات إدارية على الدوام، وكانت الصفحة الرئيسية تضع غرفة العمليات العامة وقائمة حلقات القناة فوق بعضهما. يوجد شريط مراحل جيد للحلقة لكن يصعب إدراك أنه المسار اليومي الأساسي بسبب تزاحم القوائم. آلية التحديث كانت تتحرك تلقائيًا بعد عد تنازلي، وفي الخادم كانت تستطيع إنشاء commits تلقائية ومحاولة merge أثناء وجود تعديلات محلية؛ وهذا غير مناسب لاستوديو يحتوي على أعمال إنتاج غير مكتملة. ملفات المفاتيح `.env` منفصلة بين Git worktrees، ولذلك تظهر خدمة «غير مضافة» في نسخة جديدة وإن بقيت محفوظة في نسخة أخرى.

## 2. هيكل المعلومات المستهدف
- **المستوى الأول — الشغل اليومي:** القناة ← الحلقة ← البحث ← السكريبت ← الستوري بورد ← الصوت ← المشاهد ← النشر. مصدر الحقيقة هو شريط مراحل الحلقة الحالي، وليس قائمة مهام موازية.
- **المستوى الثاني — غرفة العمليات:** التقويم، حلقات القنوات الثلاث، بنك الأفكار، توحيد المتابعة؛ شاشة بديلة لا تُعرض متراكبة مع قائمة حلقات القناة.
- **المستوى الثالث — إدارة الاستوديو:** معلومات القناة، الهوية، مكتبة الأصول، الاتصالات والمفاتيح. جميعها متاحة لكن في قائمة إدارة واحدة، وليست أزرارًا تضغط على الرأس.
- **الوظائف غير اليومية:** التقرير الآلي، كشف الأصول، الجودة التقنية، سجل الرندر؛ تظهر عند مرحلتها فقط وتظل قابلة للوصول للمختص.

## 4. التغييرات المنفذة في هذا الفرع
1. الرأس: نقل صفحات الهوية والمكتبة والقناة والإعدادات إلى عنصر «إدارة الاستوديو» واحد، متجاوب مع الشاشات الصغيرة.
2. الرئيسية: اختيار حصري بين «حلقات القناة الحالية» و«جميع القنوات · غرفة العمليات» بدل تكديس لوحتي العرض.
3. دليل عمل سريع اختياري مُغلق افتراضيًا، يشرح الطريق دون إنشاء لوحة تحكم جديدة.
4. إيقاف عدّ تحديث GitHub التلقائي، واشتراط إجراء واعٍ وموافقة صريحة.
5. خادم التحديث: لا يتدخل في worktrees المنفصلة ولا في حالة Git غير النظيفة؛ لا يحفظ commits تلقائية ولا يغيّر ملفات مستخدم؛ تحديث `main` نظيف فقط بسرعة أمامية.
6. دعم `BAL_ENV_FILE` المحدد صراحةً عند بدء Vite لاستعمال ملف أسرار مركزي؛ لا يسحب الملفات سرًا من المجلد الأصلي.
7. شرح مصدر المفاتيح للمستخدم والتحذير عند إزالة مفتاح من ملف قد يكون مشتركًا.

## 5. ما لم يُنفذ بعد — أولوية لاحقة
- **P0:** اختبار البوابة الرئيسية على Mac ومسار كامل بحلقة من كل قناة، وبخاصة انتقالات الحالة بين المراحل.
- **P0:** تنفيذ نسخ احتياطي/استرجاع للحلقات والتأكد من أن حذف الحلقة لا يزيل تاريخ عمل غير مقصود.
- **P1:** تبسيط صفحة المشاهد نفسها: فصل تحرير بيانات المشهد، المعاينة، المشاكل، والإعدادات المتقدمة إلى أقسام متدرجة.
- **P1:** شريط تشخيص للصوت والخدمات يميّز «المفتاح في ملف آخر» من «المفتاح غير صالح» دون عرض الأسرار.
- **P1:** تعميم مراجعة الفحص التقني على القنوات الثلاث، وإثبات التطابق الفعلي للمعاينة والقياس.
- **P2:** اختصار شاشة القناة والمكتبة والإعدادات إلى نموذجين «أساسي/متقدم» مع قابلية البحث والعودة للسياق السابق.
- **P2:** توحيد رسائل النجاح والخطأ والمساعدة والتأكيدات وإضافة اختبارات واجهة end-to-end.

## 6. سياسة الدمج
لا تغيير على ملفات السكريبتات أو الخطط أو الأصول أو الهوية. اجتياز `npm run check` ضروري، لكنه لا يغني عن فحص المتصفح. لا دمج إلى `main` قبل التأكد من قابلية الدمج ومن نجاح CI، والحفاظ على نسخة العمل الأصلية دون أي Git reset/clean.
