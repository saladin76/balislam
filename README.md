# بالإسلام — منظومة الإنتاج

منظومة تحوّل سكريبت الحلقة الأسبوعية إلى فيديو 16:9 وستة مقاطع 9:16، بهوية القناة الثابتة.
المرجع الكامل: وثيقة «المواصفات التقنية» و«أصول كتابة السكريبت».

## التشغيل لأول مرة

```bash
npm install
npm run app            # الاستوديو على http://127.0.0.1:4321
```

أسهل طريقة لإضافة المفاتيح: تبويب **الإعدادات** في الاستوديو (يحفظها في `.env` على جهازك فقط، ويعرض آخر 4 أحرف منها فقط، ويختبر الاتصال ويعرض أصواتك لتختار المستنسخ منها). أو يدويًا: `cp .env.example .env` ثم املأه. ملف `.env` لا يُرفع إلى GitHub أبدًا.

المفاتيح:

| المفتاح | من أين |
|---|---|
| `ELEVENLABS_API_KEY` | ElevenLabs ← Profile ← API Keys |
| `ELEVENLABS_VOICE_ID` | معرّف صوتك المستنسخ (Voices ← صوتك ← ID) |
| `QF_CLIENT_ID` / `QF_CLIENT_SECRET` | بوابة مطوري Quran Foundation |
| `QF_ENV` | `prelive` للتجربة، `production` بعد الموافقة |

## من السكريبت إلى النشر بأمر واحد

```bash
npx bal make 002
```

يفحص السكريبت ← يجلب نصوص الآيات ← يولّد خطة المشاهد ← يولّد الصوت (المشاهد التي لم تتغير لا يُعاد توليدها) ← يرندر الحلقة والشورتس الستة ← يجهّز الصور المصغّرة والوصف وملفات الترجمة وقائمة النشر في `channels/balislam/episodes/002-…/out/package/`.
يتوقف قبل صرف أي رصيد إن وُجد خطأ في السكريبت، ويرفض النسخة النهائية إن بقيت بطاقة آية بنص مؤقت أو حديث بلا نص. للمعاينة قبل الصوت: `npx bal make 002 --no-voice`.

## استوديو بالإسلام (الواجهة)

```bash
npm run app        # ثم افتح http://127.0.0.1:4321
```

- **الرئيسية:** كل حلقات القناة ومرحلة كل منها (سكريبت ← آيات ← صوت ← رندر ← نشر) والخطوة التالية.
- **المشاهد:** قائمة المشاهد، ومعاينة حية (مشهد / فصل / حلقة، أفقي وعمودي)، وإعدادات كل مشهد: القالب، النصوص، العنصر من المكتبة بالبحث، الشخصية ووضعيتها، الخلفية، المدة، المؤثرات. كل تعديل يُحفظ تلقائيًا في `plan.json`. ومنها ترندر الحلقة أو أي فصل كشورت.
- **السكريبت:** محرر بفحص مباشر أثناء الكتابة. الحفظ (Ctrl+S) يحدّث المشاهد ويُبقي اختياراتك اليدوية.
- **النشر:** «اصنع النسخة النهائية» (= `bal make`) أو معاينة بلا صوت، مع سجل التقدم؛ ثم الفيديو والشورتس والصور المصغّرة للمشاهدة، والعنوان والوصف والوسوم بأزرار نسخ، وقائمة التحقق قبل الرفع (تُحفظ)، وتسجيل تاريخ النشر ورابطه.
- **الهوية:** ألوان كل ثيم (مع فحص وضوح النص)، ألوان العناصر والشخصيات والشعار، أحجام الخطوط، سرعة الحركة. معاينة حية قبل الحفظ، وزر لاسترجاع الأصل. تُحفظ في `channels/<القناة>/identity.json`.
- **المكتبة:** العناصر (301) بالبحث والفئات مع نسخ المعرّف، والشخصيات بوضعياتها، والمؤثرات الصوتية للاستماع وتوليد الناقص.
- **القناة:** الاسم والشعار واللغة، المجالات وثيم كل مجال ووسومه، القواعد، إعدادات يوتيوب، ترجمة معاني الآيات للقنوات غير العربية، وإنشاء قناة جديدة.
- **الإعدادات:** مفاتيح ElevenLabs وQuran Foundation، اختبار الاتصال، واختيار الصوت.

الواجهة تعمل على جهازك فقط وتعدّل نفس الملفات التي تستخدمها الأوامر، فلا يتعارض العمل بها مع العمل بالأوامر. للتجربة افتح الحلقة `000` (حلقة تجريبية).

## الأوامر الجاهزة الآن

| الأمر | ماذا يفعل |
|---|---|
| `npx bal new 002 family-conflict -d family -t "عنوان الحلقة؟"` | ينشئ مجلد حلقة بقالب السكريبت |
| `npx bal check 002` | يفحص السكريبت (الفصول، المراجع، الاستشهادات، الأسلوب، المدة) قبل صرف أي رصيد |
| `npx bal check 002 --json` | النتيجة نفسها بصيغة JSON |
| `npx bal stills` | يرندر لوحات الهوية لكل ثيم في `renders/brand/` |
| `npx bal plan 002` | يولّد خطة المشاهد `plan.json` من السكريبت (مع إبقاء تعديلاتك) |
| `npx bal render 002` | يرندر الحلقة من الخطة (`--portrait` للعمودي، `--chapter 3` لفصل واحد كشورت) |
| `npx bal quran 002` | يجلب نصوص الآيات بالرسم العثماني من Quran Foundation |
| `npx bal voice 002 --dry-run` | يحسب الحروف والرصيد قبل التوليد؛ بدون `--dry-run` يولّد. `--scene c2-s1` لمشهد واحد |
| `npx bal sfx --list` | حالة المؤثرات الصوتية؛ `--missing` لتوليد الناقص منها |
| `npx bal package 002` | ملفات النشر من الصوت والخطة الحاليين (`--skip-video` للنصوص والصور فقط) |
| `npx bal make 002` | كل ما سبق بالترتيب |
| `npx bal elements` | يصدّر مكتبة العناصر: SVG لكل ثيم + `manifest.json` + `catalog.html` في `assets/elements/` |
| `npx bal preview reel-paper` | يرندر فيديو معاينة القوالب (أو `--stills 30,120` للقطات ثابتة) في `renders/previews/` |
| `npm run studio` | يفتح Remotion Studio للمعاينة |
| `npm test` / `npm run typecheck` | الاختبارات وفحص الأنواع |

المجالات: `psychology` (حبر وورق) · `family` (دفء البيت) · `money` (ليلٌ هادئ) · `knowledge` (أقواس دافئة).

## القنوات واللغات

المحرك واحد لكل القنوات؛ القناة مجلد بيانات:

```
channels/balislam/
  channel.json          الاسم، اللغة، المجالات وثيم كل مجال، القواعد (موسيقى، قرآن، حديث)، وسوم يوتيوب
  identity.json         الألوان والخطوط والحركة (يُعدَّل من الاستوديو)
  identity.default.json الأصل لزر «استرجاع»
  pronunciation.json    قاموس النطق
  episodes/             الحلقات
```

- كل الأوامر تعمل على القناة الافتراضية (`defaultChannel` في `config.json`)، ولقناة أخرى: `npx bal --channel tech new 001 …`.
- قناة جديدة: `npx bal channel new tech -n "تقنية بوعي" -l ar --no-quran` ثم عدّل مجالاتها في `channel.json` وألوانها من الاستوديو. `npx bal channel list` يعرضها.
- الاستوديو يُظهر منتقي القناة عند وجود أكثر من قناة.
- لغة الحلقة من القناة، أو بحقل `lang: tr` في ترويسة السكريبت. حزم اللغات في `src/i18n/packs.ts`: العربية والتركية والإنجليزية جاهزة. كلمات السكريبت بلغته (`Bölüm` / `Chapter`، `[sahne: …]` / `[scene: …]`، `[ayet: …]` / `[verse: …]`)، والقوالب كلها تنعكس من اليسار لليمين، والوصف المنشور على يوتيوب يُكتب بلغة الحلقة.
- مرجع الآية يُكتب بالعربية أو باللاتينية أو بالأرقام: `[آية: النجم 39]` = `[verse: An-Najm 39]` = `[verse: 53:39]`. نص الآية يبقى عربيًا دائمًا، وفي القنوات غير العربية تظهر تحته ترجمة المعنى التي تختارها من تبويب «القناة» (تُجلب من Quran Foundation مع نص الآية).

## مكتبة العناصر

كل ما تُبنى منه المشاهد في مكان واحد، ويتلوّن تلقائيًا بثيم الحلقة:

- `brand/elements/categories/` — العناصر مقسّمة على 11 فئة (رموز، نفس ومشاعر، طبيعة، بيت، حياة يومية، مال، علم، رموز إسلامية، أيدٍ، إطارات، خلفيات).
- `characters/Character.tsx` — 5 شخصيات بلا ملامح × 12 وضعية.
- `brand/sfx.ts` — سجل المؤثرات الصوتية والآهات (بلا موسيقى).
- `brand/elements/GUIDE.md` — دليل رسم أي عنصر جديد وضوابطه.
- `assets/elements/catalog.html` — الكتالوج المصوّر لكل ما سبق.

في الكود: `<Element id="book-open" theme={theme} size={240} />`

## إعداد المشهد من السكريبت مباشرة

كل حقول القالب يمكن كتابتها في سطر العلامة، والقوائم تُفصل بـ «؛»:

```
[مشهد: list | title=ثلاث خطوات صغيرة | items=حدّد مهمة واحدة؛ اعمل خمس دقائق؛ كافئ نفسك | style=numbered]
[مشهد: timeline | title=كيف يكبر التأجيل | events=اليوم الأول — أؤجل؛ بعد شهر — يصبح عادة]
[مشهد: symbolic | element=seed | secondElement=tree | relation=becomes | effect=grow]
```
أو اترك العلامة بسيطة `[مشهد: list]` واملأ الحقول من الاستوديو.

## صيغة الحديث في السكريبت

```
[حديث: صحيح البخاري 6446 | ليس الغنى عن كثرة العرض، ولكن الغنى غنى النفس | عن أبي هريرة رضي الله عنه]
```
المصدر | النص كما في المصدر | الراوي. والدرجة تؤخذ من قسم الاستشهادات.

## قواعد ثابتة

- الأخطاء توقف الحلقة؛ التنبيهات للمراجعة فقط.
- لا يُكتب نص الآية داخل التعليق؛ تُستدعى بـ `[آية: النجم 39]` وتظهر نصًّا من المصدر المعتمد.
- الحديث بدرجة صحيح أو حسن فقط، مع جهة التحقق في قسم الاستشهادات.
- لا موسيقى؛ مؤثرات صوتية وآهات بشرية فقط.
