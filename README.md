# بالإسلام — منظومة الإنتاج

منظومة تحوّل سكريبت الحلقة الأسبوعية إلى فيديو 16:9 وستة مقاطع 9:16، بهوية القناة الثابتة.
المرجع الكامل: وثيقة «المواصفات التقنية» و«أصول كتابة السكريبت».

## التشغيل لأول مرة

```bash
npm install
cp .env.example .env   # ضع المفاتيح هنا فقط — لا تُرفع إلى GitHub أبدًا
```

## الأوامر الجاهزة الآن

| الأمر | ماذا يفعل |
|---|---|
| `npx bal new 002 family-conflict -d family -t "عنوان الحلقة؟"` | ينشئ مجلد حلقة بقالب السكريبت |
| `npx bal check 002` | يفحص السكريبت (الفصول، المراجع، الاستشهادات، الأسلوب، المدة) قبل صرف أي رصيد |
| `npx bal check 002 --json` | النتيجة نفسها بصيغة JSON |
| `npx bal stills` | يرندر لوحات الهوية لكل ثيم في `renders/brand/` |
| `npm run studio` | يفتح Remotion Studio للمعاينة |
| `npm test` / `npm run typecheck` | الاختبارات وفحص الأنواع |

المجالات: `psychology` (حبر وورق) · `family` (دفء البيت) · `money` (ليلٌ هادئ) · `knowledge` (أقواس دافئة).

## قواعد ثابتة

- الأخطاء توقف الحلقة؛ التنبيهات للمراجعة فقط.
- لا يُكتب نص الآية داخل التعليق؛ تُستدعى بـ `[آية: النجم 39]` وتظهر نصًّا من المصدر المعتمد.
- الحديث بدرجة صحيح أو حسن فقط، مع جهة التحقق في قسم الاستشهادات.
- لا موسيقى؛ مؤثرات صوتية وآهات بشرية فقط.
