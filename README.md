# بالإسلام — منظومة الإنتاج

منظومة تحوّل سكريبت الحلقة الأسبوعية إلى فيديو 16:9 وستة مقاطع 9:16، بهوية القناة الثابتة.
المرجع الكامل: وثيقة «المواصفات التقنية» و«أصول كتابة السكريبت».

## التشغيل لأول مرة

```bash
npm install
cp .env.example .env   # ضع المفاتيح هنا فقط — لا تُرفع إلى GitHub أبدًا
```

## استوديو بالإسلام (الواجهة)

```bash
npm run app        # ثم افتح http://127.0.0.1:4321
```

- **الحلقة:** قائمة المشاهد، ومعاينة حية (مشهد / فصل / حلقة، أفقي وعمودي)، وإعدادات كل مشهد: القالب، النصوص، العنصر من المكتبة بالبحث، الشخصية ووضعيتها، الخلفية، المدة، المؤثرات. كل تعديل يُحفظ تلقائيًا في `plan.json`. ومنها ترندر الحلقة أو أي فصل كشورت.
- **السكريبت:** محرر بفحص مباشر أثناء الكتابة. الحفظ (Ctrl+S) يحدّث المشاهد ويُبقي اختياراتك اليدوية.
- **الهوية:** ألوان كل ثيم (مع فحص وضوح النص)، ألوان العناصر والشخصيات والشعار، أحجام الخطوط، سرعة الحركة. معاينة حية قبل الحفظ، وزر لاسترجاع الأصل. تُحفظ في `brand/identity.json`.

الواجهة تعمل على جهازك فقط وتعدّل نفس الملفات التي تستخدمها الأوامر، فلا يتعارض العمل بها مع العمل بالأوامر. للتجربة افتح الحلقة `000` (حلقة تجريبية).

## الأوامر الجاهزة الآن

| الأمر | ماذا يفعل |
|---|---|
| `npx bal new 002 family-conflict -d family -t "عنوان الحلقة؟"` | ينشئ مجلد حلقة بقالب السكريبت |
| `npx bal check 002` | يفحص السكريبت (الفصول، المراجع، الاستشهادات، الأسلوب، المدة) قبل صرف أي رصيد |
| `npx bal check 002 --json` | النتيجة نفسها بصيغة JSON |
| `npx bal stills` | يرندر لوحات الهوية لكل ثيم في `renders/brand/` |
| `npx bal plan 002` | يولّد خطة المشاهد `plan.json` من السكريبت (مع إبقاء تعديلاتك) |
| `npx bal render 002` | يرندر الحلقة من الخطة (`--portrait` للعمودي، `--chapter 3` لفصل واحد كشورت) |
| `npx bal elements` | يصدّر مكتبة العناصر: SVG لكل ثيم + `manifest.json` + `catalog.html` في `assets/elements/` |
| `npx bal preview reel-paper` | يرندر فيديو معاينة القوالب (أو `--stills 30,120` للقطات ثابتة) في `renders/previews/` |
| `npm run studio` | يفتح Remotion Studio للمعاينة |
| `npm test` / `npm run typecheck` | الاختبارات وفحص الأنواع |

المجالات: `psychology` (حبر وورق) · `family` (دفء البيت) · `money` (ليلٌ هادئ) · `knowledge` (أقواس دافئة).

## مكتبة العناصر

كل ما تُبنى منه المشاهد في مكان واحد، ويتلوّن تلقائيًا بثيم الحلقة:

- `brand/elements/categories/` — العناصر مقسّمة على 11 فئة (رموز، نفس ومشاعر، طبيعة، بيت، حياة يومية، مال، علم، رموز إسلامية، أيدٍ، إطارات، خلفيات).
- `characters/Character.tsx` — 5 شخصيات بلا ملامح × 12 وضعية.
- `brand/sfx.ts` — سجل المؤثرات الصوتية والآهات (بلا موسيقى).
- `brand/elements/GUIDE.md` — دليل رسم أي عنصر جديد وضوابطه.
- `assets/elements/catalog.html` — الكتالوج المصوّر لكل ما سبق.

في الكود: `<Element id="book-open" theme={theme} size={240} />`

## قواعد ثابتة

- الأخطاء توقف الحلقة؛ التنبيهات للمراجعة فقط.
- لا يُكتب نص الآية داخل التعليق؛ تُستدعى بـ `[آية: النجم 39]` وتظهر نصًّا من المصدر المعتمد.
- الحديث بدرجة صحيح أو حسن فقط، مع جهة التحقق في قسم الاستشهادات.
- لا موسيقى؛ مؤثرات صوتية وآهات بشرية فقط.
