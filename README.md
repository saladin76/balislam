# استوديو القنوات — منظومة الإنتاج

منظومة واحدة تُخرج حلقات ثلاث قنوات عربية، لكل منها هويتها ومكتبتها: من السكريبت إلى فيديو 16:9 وشورتس 9:16 وحزمة النشر.
مبادئ العمل الثابتة في [`CLAUDE.md`](CLAUDE.md)، وقالب السكريبت وأصول كتابته في [`templates/script.md`](templates/script.md).

| القناة | المعرّف | الهوية المعتمدة | الخطوط | المكتبة |
|---|---|---|---|---|
| **بالإسلام** | `balislam` | «محراب النور»: ليل زمردي ونحاس وفجر، باء نقطتها شمس، ختم أحمر | الرقعة + تجوال | آيات وأحاديث ورموز إسلامية، بلا وجوه، بلا موسيقى |
| **دفاتر الزمن** | `dafatir-alzaman` | «دفتر الأفق»: دفتر كعبه ساعة رملية، غروب على صفحتيه، شريط تاريخ أحمر | الأميري + تجوال + IBM Plex Mono للسنوات | قوالب التاريخ وأماكنه، شخصيات تاريخية بملامح (لا نبي ولا صحابي) |
| **زبدة الكتب** | `zubdat-alkutub` | «القلم المميِّز»: أبيض وأسود، والفسفوري للفكرة فقط | لاله زار + تجوال | خلاصات الكتب، بلا رموز دينية |

الهويات مسجّلة في [`brand/identity/approved.ts`](brand/identity/approved.ts) ومقفلة باختبار، فلا تتسرب بصمة قناة إلى أخرى.

## فتح المشروع على الماك

أول مرة (المستودع خاص، فيلزم أن يكون حساب GitHub مسجّلًا على الجهاز):

```bash
git clone https://github.com/saladin76/balislam.git
cd balislam
npm install
npm run app            # الاستوديو على http://127.0.0.1:4321
```

بعد ذلك: دبل كليك على **`start-studio.command`** (يحدّث المشروع ويفتح الاستوديو)، أو من الطرفية:

```bash
cd balislam
git pull
npm install            # فقط إن تغيّرت الحزم
npm run app
```

**بداية نظيفة** (عند الحاجة فقط، مثل الانتقال للهويات الجديدة): دبل كليك على **`fresh-start.command`**. يطابق المشروع مع GitHub تمامًا، وينقل كل محتوى الحلقات القديمة على جهازك (صوت، فيديو، صور، حلقات محذوفة) إلى أرشيف في `~/balislam-archive/`، ثم يفتح الاستوديو. لا يلمس المفاتيح ولا المؤثرات الصوتية ولا التلاوات المرخّصة.

المفاتيح من تبويب **الإعدادات** في الاستوديو (تُحفظ في `.env` على جهازك فقط ولا تُرفع أبدًا)، أو يدويًا: `cp .env.example .env`.

| المفتاح | من أين |
|---|---|
| `ELEVENLABS_API_KEY` | ElevenLabs ← Profile ← API Keys |
| `ELEVENLABS_VOICE_ID` | معرّف صوتك المستنسخ |
| `QF_CLIENT_ID` / `QF_CLIENT_SECRET` | بوابة مطوري Quran Foundation |
| `QF_ENV` | `prelive` للتجربة، `production` بعد الموافقة |

نموذج الصوت الافتراضي **Eleven v4** (الأحدث)، وجودة الصوت mp3 بمعدل 192 kbps. صوتك الاحترافي يحتاج تدريبًا على النموذج في ElevenLabs (My Voices ← مرّر على صوتك ← زر + بجانب Eleven v4)، وتبويب «الإعدادات» يعرض حالة التدريب لكل نموذج ويتيح التبديل. المنظومة تبني كل طلب بحسب قدرات النموذج: في v4 تُطبَّق السرعة بعد التوليد بتمديد زمني يحفظ طبقة صوتك، وتُنقل النبرة بأمر أداء لا يظهر أبدًا في الترجمة على الشاشة.

## الاستوديو

منتقي القناة أعلى الواجهة يبدّل كل شيء: الهوية والمكتبة والحلقات.

- **غرفة العمليات:** جدول القنوات الثلاث، والأفكار، وتنبيه تكرار الأسلوب.
- **الرئيسية:** حلقات القناة ومرحلة كل منها (سكريبت ← آيات ← صوت ← رندر ← نشر).
- **المشاهد:** معاينة حية (مشهد / فصل / حلقة، أفقي وعمودي) وإعدادات كل مشهد، تُحفظ تلقائيًا في `plan.json`.
- **السكريبت:** محرر بفحص مباشر؛ الحفظ يحدّث المشاهد ويُبقي اختياراتك اليدوية.
- **النشر:** النسخة النهائية، الفيديو والشورتس والمصغّرات، العناوين والوصف والوسوم وحزمة الانتشار، وقائمة التحقق.
- **الهوية:** ألوان الثيمات الأربعة وأحجام الخطوط والحركة، بمعاينة حية.
- **المكتبة:** مكتبة القناة الحالية فقط — القوالب، أماكن التصوير، الشخصيات، العناصر، المؤثرات.
- **القناة:** بطاقة الهوية المعتمدة (الشعار، الألوان، الخطوط، الثيمات، المكتبة)، والأساسيات، والمجالات، والقواعد، ويوتيوب، وبصمة القناة (الافتتاحية والمصغّرة مقفلتان بعد الاعتماد)، والصوت، والجدول، والأساليب.
- **الإعدادات:** المفاتيح واختبار الاتصال والصوت.

## من السكريبت إلى النشر

```bash
npx bal make 001                         # القناة الافتراضية
npx bal --channel zubdat-alkutub make 001
npx bal make 001 --no-voice              # معاينة بلا صرف رصيد
```

يفحص السكريبت ← يجلب الآيات ← يولّد المشاهد ← الصوت ← يرندر الحلقة والشورتس ← حزمة النشر في `channels/<القناة>/episodes/<الحلقة>/out/package/`.
الحلقة تُرندر بأعلى جودة (4K، H.264 crf 14، صوت 320k)، ثم تشاهدها في «النشر» وتضغط «اعتمد النسخة الأساسية»، وبعدها «اصنع الشورتس والريلز» (أو `npx bal package 001 --shorts`). كل ملف له زر تنزيل بجودته الأصلية.
يتوقف قبل صرف أي رصيد عند خطأ، ويرفض النسخة النهائية عند: آية بنص مؤقت، حديث بلا نص، عنصر ليس من مكتبة القناة، حركة أقل من 80%، أو أي أثر لأدوات الإنتاج.

| الأمر | ماذا يفعل |
|---|---|
| `npx bal new 001 slug -d <مجال> -t "العنوان"` | ينشئ حلقة بقالب السكريبت |
| `npx bal check 001` | يفحص السكريبت قبل صرف أي رصيد |
| `npx bal plan 001` | يولّد خطة المشاهد مع إبقاء تعديلاتك |
| `npx bal quran 001` | يجلب نصوص الآيات من Quran Foundation |
| `npx bal voice 001 --dry-run` | يحسب الرصيد؛ بدون `--dry-run` يولّد الصوت |
| `npx bal render 001` | يرندر الحلقة (`--portrait`، `--chapter 3`) ويقيس الحركة |
| `npx bal motion ملف.mp4` | مقياس الحركة والمقاطع الساكنة |
| `npx bal package 001` | ملفات النشر |
| `npx bal art [القناة]` | صورة الحساب وأغلفة المنصات بهوية القناة في `renders/brand/` |
| `npx bal elements [القناة]` | مكتبة القناة بهويتها (SVG + كتالوج) في `renders/elements/<القناة>/` |
| `npx bal channel list` / `channel new` | القنوات؛ القناة الجديدة تبدأ بهوية محايدة حتى تُعتمد هويتها |
| `npm run studio` | Remotion Studio للمعاينة |
| `npm run check` | فحص الأنواع وكل الاختبارات (يعمل على GitHub مع كل دفعة) |

## بنية المشروع

```
app/                  الاستوديو (واجهة React + خادم محلي)
  src/tabs/           تبويبات الواجهة (القناة، المكتبة، المشاهد، النشر…)
  server/             واجهة الملفات والتحديث
brand/                ما تُرسم به القنوات
  identity/           سياق الهوية + approved.ts (الهويات المعتمدة)
  logo/               الشعارات والشارات
  elements/           العناصر بفئاتها + GUIDE.md لرسم عنصر جديد
  sets/               أماكن التصوير المرسومة
  fonts.ts            الخطوط وملفاتها في public/fonts
characters/           الشخصيات بلا ملامح، والشخصيات التاريخية
channels/<القناة>/    بيانات كل قناة
  channel.json        الاسم، المجالات، القواعد، يوتيوب، البصمة، الأساليب
  identity.json       الألوان والخطوط والحركة (identity.default.json للاسترجاع)
  pronunciation.json  قاموس النطق
  episodes/           الحلقات (السكريبت والخطة؛ الصوت والفيديو لا تُرفع)
src/
  channel/            تحميل القنوات، library.ts (مكتبة كل قناة)، إنشاء قناة
  script/  plan/      قراءة السكريبت وفحصه، وتوليد المشاهد وفحصها
  voice/  quran/      الصوت والتشكيل، والآيات والتلاوة
  remotion/           القوالب والافتتاحيات والمصغّرات وصور القناة
  render/  package/   الرندر ومقياس الحركة، وحزمة النشر وفحص الآثار
  cli/                أوامر bal
tests/                الاختبارات (منها قفل الهويات ومكتبة كل قناة)
tools/voice-prep/     تجهيز تسجيلات الصوت قبل الاستنساخ
templates/script.md   قالب السكريبت
renders/              مخرجات مولَّدة (لا تُرفع)
```

## إعداد المشهد من السكريبت

```
[مشهد: list | title=ثلاث خطوات صغيرة | items=حدّد مهمة واحدة؛ اعمل خمس دقائق؛ كافئ نفسك | style=numbered]
[مشهد: symbolic | element=seed | secondElement=tree | relation=becomes | effect=grow]
[مشهد: kinetic-text | emphasis=راحة، يكبر | stage=dark]
```

أسلوب الحلقة بحقل `style:` في ترويسة السكريبت (`motion`، `board`، `glow`، `kinetic`، أو معرّف قالب). القائمة في `src/plan/styles.ts`، والأساليب المتاحة لكل قناة من مكتبتها. قبل أي حلقة: ستوري بورد بـ ٣–٤ أساليب ثم اعتماد.

## التشكيل والحديث

- نسخة مشكولة باسم `tashkeel.md` بجوار `script.md` تُستعمل للنطق فقط، والترجمة على الشاشة بلا تشكيل.
- `[حديث: صحيح البخاري 6446 | النص كما في المصدر | الراوي]`، بدرجة صحيح أو حسن فقط.
- لا يُكتب نص الآية في التعليق: `[آية: النجم 39]` ويُجلب من المصدر المعتمد.
