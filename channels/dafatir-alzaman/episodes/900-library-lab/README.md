# مختبر مكتبة «دفتر الأفق» — «دفاتر الزمن»

اختبارات بصرية لمشاهد المكتبة العامة (الأمر 015): كل مشهد عام يُجرَّب هنا بنص مختلف عن الحلقة 001، بلا صوت ولا موسيقى.
**لا يُنشر أبدًا ولا يُعد حلقة.** الاستشهادات فيه للاختبار البصري فقط، ولا تُنقل إلى حلقة قبل توثيقها في بحثها وسجل التوثيق.

| الفصل | المشاهد | ما يختبره |
| --- | --- | --- |
| ١ | `chapter`، `lib-term` ×٣ | عنوان فصل، مصطلح بالحبر بلا تشكيل وبتشكيل (الحَضَارَة) وبلون الطين، شرح كلمة كلمة، مصدر غير قرآني، ختم قرآني بمرجعه، تعليق في الهامش، والسكون عند ذكر الله |
| ٢ | `lib-gloss` ×٢ | أصل غير قرآني (ابن خلدون) مع تعليق، ومرجع قرآني بلا نص مع حاشية تفسير وتعليق |
| ٣ | `lib-compare` ×٢ | مسألة مفتوحة (قصاصة فوق الكعب)، وترجيح بختم وتخفيت الطرف الآخر، ونص بتشكيل جزئي |
| ٤ | `lib-timeline`، `lib-evidence` | خط زمني بفجوة بلا سجل والكاميرا تتتبعه، ثم استمرار بلا قلب صفحة إلى شواهد أثرية وحدودها |

الرفع: `npx bal -c dafatir-alzaman upload-preview 900 library <الملف> --title … --note …`
الخانة `library`: آخر نسخة فقط؛ النسخ السابقة في سجل git.
