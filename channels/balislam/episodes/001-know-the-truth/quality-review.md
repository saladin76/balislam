# مراجعة الجودة — بوابات الاعتماد
**النتيجة الحالية: غير جاهزة للإنتاج النهائي.**

| البوابة | دليل القبول | الحالة |
|---|---|---|
| البحث | كل شاهد مهم موثق وسياقه مراجع | غير مكتمل |
| الشرعي | مراجعة الآيات والأدعية والتفسيرات | غير مكتمل |
| السرد | النص متدرج بلا تكرار مخل، والفصول مستقلة | مراجعة مطلوبة |
| الإخراج | لكل مشهد معنى وتكوين وحركة وتوقيت | 6 نماذج فقط؛ الباقي مطلوب |
| الهوية | القوالب والألوان والخطوط والعناصر مطابقة | موثق نظريًا؛ يحتاج معاينة |
| الصوت | تشكيل مطابق + تجربة نطق + توجيه أداء | غير مكتمل |
| المؤثرات | الملفات موجودة ومسموعة ومضبوطة | غير مثبت |
| التلاوات | النص والقارئ والصوت متطابقون | غير مكتمل |
| التقنية | فحوص المشروع والرندر دون أخطاء | لم يُختبر |
| المشاهدة | مشاهدة الفيديو النهائي كاملًا وتسجيل الملاحظات | لم تحدث |

## معايير قبول المشهد
- لا رمز بلا علاقة دقيقة بالنص.
- لا حركة لمجرد إبقاء الشاشة متحركة.
- لا ظهور مبكر لنتيجة لم يصل إليها الراوي بعد.
- لا تحريف في آية أو دعاء أو إسناد.
- لا انتقال يقطع جملة أو يوهم بعلاقة سببية غير صحيحة.
- لا تكرار قالب يخلق رتابة يمكن تجنبها.
- لا اعتماد إلا بعد مشاهدة المشهد والاستماع إليه.

## سجل قرار
- اتجاه إخراجي معتمد: **معلّق**.
- عينة مرئية وصوتية معتمدة: **لا**.
- مراجعة جميع المشاهد: **لا**.
- السماح بالرندر النهائي: **لا**.
- السماح بالنشر: **لا**.
