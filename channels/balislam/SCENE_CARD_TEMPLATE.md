# قالب بطاقة إخراج المشهد

> انسخ بطاقة لكل مشهد إلى `storyboard.md` في مجلد الحلقة. القالب وثائقي؛ ليس ملفًا يقرأه المحرك تلقائيًا.

## SC-000 — الفصل: …
- **النص الحرفي للراوي:** …
- **المعنى الذي يجب أن يفهمه المشاهد:** …
- **نوع الدليل:** آية / حديث / مرجع / تحليل / مثال افتراضي
- **مرجع المصدر وحالة التحقق:** …
- **التكوين:** موضع الشخصية والخلفية والعناصر والمساحات الآمنة للنص.
- **العناصر المحددة:** كل عنصر واسمه ووظيفته.
- **تتابع الحركة:** الحدث الذي يبرر الحركة، وما يدخل ويخرج.
- **المحاذاة:** عبارة الراوي أو الكلمة التي يبدأ معها كل حدث.
- **الكاميرا:** ثابتة أو مسار محدد وسببه.
- **الانتقال:** القطع أو الاستمرار وعلاقته بالمشهد التالي.
- **المؤثر:** صمت، أو معرف موجود ومتحقق منه؛ موضعه ومستواه.
- **المدة:** تقديرية إلى حين تسجيل التعليق ومحاذاته.
- **التنفيذ في الاستوديو:** القالب والحقول المدعومة في `plan.json`.
- **ما يحتاج إلى تطوير:** `requires-engineering` أو «لا شيء».
- **المراجعة:** قيد التنفيذ / يحتاج تعديل / معتمد بعد المعاينة.
