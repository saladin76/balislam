# حزمة التأسيس الشاملة — قناة «بالإسلام»

**الإصدار:** 2026-11-04 | **النوع:** مرجع تأسيس وإنتاج | **الحالة:** وثائق أصلية محفوظة؛ التعارضات قيد الحسم.

## الغرض
هذه الحزمة تسلّم إلى Claude لتثبيت مرجعيات قناة «بالإسلام» في الاستوديو، لا لإنتاج حلقة تلقائيًا.
لا تتضمن أي اعتماد للحلقة 001 السابقة أو معايناتها أو للنسخة التجريبية 000-demo.

## المحتويات
- `01_official_references/`: الوثائق الرسمية التسع الأصلية، دون تعديل المحتوى.
- `02_motion_and_production/`: دليل الموشن جرافيك وتعليمات منهج الإنتاج المتاحة.
- `03_visual_identity/`: الصورة المعتمدة «محراب النور» والحزمة الرسومية للقناة.
- `04_execution/`: تكليف Claude وقائمة نقاط الحسم وبوابة الجاهزية.
- `manifest.json`: قائمة الملفات وبصمات SHA-256 للتحقق.

## حدود الاعتماد
الوثائق الأصلية مصدر الحقيقة في مجالاتها؛ هذه الحزمة لا تصدر قرارات جديدة بشأن تعارضاتها. تعليمات التنفيذ المرفقة تنظيمية فقط ولا تتقدم على الميثاق أو الهوية الرسمية. لا تعتبر القواعد القديمة في الشيفرة مرجعًا مستقلًا.

## طريقة التسليم
أرسل الملف ZIP كاملًا إلى Claude. عليه استيراد المرجعيات كما هي، والتحقق من البصمات، وإعداد تقرير تعارضات قبل أي تعديل للهوية أو المحتوى أو سياسات النشر.
