# بوابة الجاهزية لبدء الإنتاج

- [ ] جميع المرجعيات الرسمية موجودة، قابلة للقراءة، وتطابق البصمات.
- [ ] التعارضات المهمة مصنفة ومعروضة لصاحب القناة، والقرارات موثقة.
- [ ] الهوية البصرية والصوتية ثابتة دون تعديلات غير معتمدة.
- [ ] قواعد التحقق الشرعي والمصادر متفقة مع الوثائق المعتمدة.
- [ ] قواعد المعاينات والرفع والاستبدال داخل الاستوديو الرئيسي واضحة.
- [ ] تم اعتماد موضوع الحلقة الجديدة والبحث والسيناريو قبل بدء التحريك.

**ممنوع تجاوز البوابة:** لا اعتماد تلقائي للحلقة السابقة أو أي نسخة صامتة، ولا إنتاج جديد قبل موافقة المدير الإبداعي وصاحب المشروع.
