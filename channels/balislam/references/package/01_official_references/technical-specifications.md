## التقنيات المختارة

لغة واحدة (TypeScript) من أول المنظومة لآخرها، حتى يكون الكود كله مفهومًا لك وقابلًا للتعديل.

| التقنية | الدور | لماذا هي |
| --- | --- | --- |
| Node.js و TypeScript | أداة الأوامر وكل منطق المنظومة | أنواع صارمة لصيغ الملفات، ولغة واحدة مع Remotion |
| Remotion | رسم المشاهد بـ React ورندرها فيديو | المشهد مكوّن React يقرأ بياناته، ويُرسم بأي مقاس |
| ElevenLabs API | توليد الصوت مع توقيت كل حرف | التوقيتات هي أساس المزامنة الآلية |
| Quran Foundation API | نص الآيات بالرسم العثماني | نص موثق لا يُكتب يدويًا |
| ffmpeg | ضبط مستوى الصوت ودمج المؤثرات والتصدير | معيار صناعة الصوت والفيديو |
| Zod | التحقق من صيغ الملفات | أي خطأ في السكريبت يظهر برسالة واضحة قبل صرف أي رصيد |
| Vitest | الاختبارات | سريع ومتوافق مع TypeScript |
| Git و GitHub (مستودع خاص) | حفظ الكود والسكريبتات والتاريخ | أرشيف كامل لكل حلقة وكل تعديل |

## صيغ الملفات

ثلاثة ملفات لكل حلقة: السكريبت الذي تكتبه، والتوقيتات التي يولدها الصوت، وخطة المشاهد التي تولدها المنظومة منهما.

**1. السكريبت `script.md`**

| العنصر | الصيغة | المعنى |
| --- | --- | --- |
| بيانات الحلقة | ترويسة `---` في أول الملف | `title`، `domain`، `episode`، و`alt_titles` (العناوين البديلة) |
| فصل | `## الفصل 1 · العنوان` | بداية فصل جديد (6 فصول بالضبط) |
| نص التعليق | فقرات عادية | ما يقرؤه الصوت |
| مشهد | `[مشهد: big-question]` | قالب المشهد للنص الذي يليه حتى المشهد التالي؛ الافتراضي «شخصية تتكلم» |
| آية | `[آية: النجم 39]` | يُدرج نص الآية من Quran Foundation وتلاوتها المرخصة إن وُجدت |
| حديث | `[حديث: صحيح البخاري 6446]` | بطاقة الحديث بمصدره؛ نصه يُكتب في التعليق ويقرؤه الصوت |
| مؤثر | `[صوت: page-turn]` | مؤثر من مكتبة `assets/sfx` في هذه اللحظة |
| جملة ربط | `bridge: …` | تُقرأ في الحلقة وتُحذف من الشورت |
| أقسام الختام | `## الاستشهادات` و`## الخطوة العملية` | تُقرأ للتحقق والوصف، ولا يُولّد لها صوت |

**2. التوقيتات `voice/timings.json`**

```json
{
  "chapter": 1,
  "audio": "ch1.mp3",
  "durationSec": 71.4,
  "words": [
    { "text": "تفتح", "start": 0.12, "end": 0.48 },
    { "text": "الهاتف", "start": 0.48, "end": 0.97 }
  ],
  "bridge": { "audio": "ch1-bridge.mp3", "durationSec": 2.6 }
}
```

**3. خطة المشاهد `plan.json`**

```ts
type Plan = {
  episode: string;            // "001"
  domain: "psychology" | "family" | "money" | "knowledge";
  theme: "paper" | "family" | "night" | "warm";
  title: string;
  chapters: Chapter[];        // 6
};

type Chapter = {
  index: number;
  title: string;
  audio: string;
  durationSec: number;
  bridge?: { audio: string; durationSec: number };
  scenes: Scene[];
};

type Scene = {
  template: TemplateId;       // "big-question" | "character-talk" | "verse-card" | …
  startSec: number;
  endSec: number;
  props: Record<string, unknown>;   // يتحقق منها Zod حسب القالب
  captions: { text: string; start: number; end: number }[][];   // أسطر من كلمات
  sfx?: { id: string; atSec: number }[];
  verse?: { key: string; textUthmani: string; surah: string; ayah: number;
            recitation?: { file: string; reciter: string; licenseFile: string } };
};
```

كل قالب مشهد يعلن مخطط `props` الخاص به، فلا تُرندر خطة فيها بيانات ناقصة.

## الأوامر ومراحل التشغيل

كل مرحلة أمر مستقل يمكن إعادته وحده، و`bal make` يشغّل السلسلة كلها. كل أمر يقرأ مخرجات الذي قبله من مجلد الحلقة.

| الأمر | ماذا يفعل | يصرف رصيدًا؟ |
| --- | --- | --- |
| `bal new 002 family-conflict` | ينشئ مجلد حلقة بقالب السكريبت | لا |
| `bal check 001` | يتحقق من السكريبت: 6 فصول، الطول، العلامات، الاستشهادات، قائمة المحظورات الآلية | لا |
| `bal quran 001` | يجلب نصوص الآيات ويخزنها في المجلد | لا |
| `bal voice 001 [--chapter 3]` | يولّد صوت الفصول (أو فصل واحد) مع التوقيتات | نعم، ElevenLabs |
| `bal plan 001` | يبني `plan.json` من السكريبت والتوقيتات | لا |
| `bal preview 001` | يفتح Remotion Studio لمعاينة الحلقة والشورتس | لا |
| `bal render 001` | يرندر الحلقة وشورتسها (بلا حد، D152) ويضبط الصوت | لا (وقت الجهاز) |
| `bal package 001` | الوصف بالفصول والمصادر، ملفات الترجمة، الصورة المصغرة | لا |
| `bal make 001` | كل ما سبق بالترتيب، ويتوقف عند أول خطأ | حسب الحاجة |

**التخزين المؤقت:** كل فصل يُحسب له بصمة (hash) من نصه وإعدادات الصوت وقاموس النطق. إذا لم يتغير الفصل لا يُعاد توليده، فتعديل فصل واحد لا يصرف رصيد الحلقة كلها.

## التكاملات

**ElevenLabs: توليد الصوت**

- الطلب: `POST /v1/text-to-speech/{voice_id}/with-timestamps`، والرد فيه الصوت (`audio_base64`) وتوقيت كل حرف (`alignment`: الحروف وبداية ونهاية كل منها بالثواني).
- نرسل كل فصل في طلب مستقل، ومعه `previous_text` و`next_text` من الفصلين المجاورين لتبقى النبرة متصلة بين الفصول.
- جملة الربط تُولّد في طلب منفصل، لتُحذف من الشورت دون قص داخل الصوت.
- قاموس النطق يُرفع إلى ElevenLabs ويُمرّر عبر `pronunciation_dictionary_locators` (حتى 3 قواميس)، إضافة إلى تصحيحات نصية قبل الإرسال.
- النموذج يُحدد بعد اختبار الصوت؛ الافتراضي في الواجهة `eleven_multilingual_v2`.
- `seed` ثابت لكل فصل لتقليل التباين عند إعادة التوليد (لا يضمن تطابقًا تامًا).

**Quran Foundation: نص الآيات**

- مصادقة OAuth2 بنوع Client Credentials ونطاق `content`، والتوكن صالح ساعة واحدة؛ نخزنه ونجدده قبل انتهائه.
- كل طلب يحمل `x-auth-token` و`x-client-id`، على المسار `/content/api/v4/…`.
- الآية تُجلب بمفتاحها (`53:39`) بالرسم العثماني، وتُخزن في مجلد الحلقة فلا تُجلب مرتين.
- بيئة الاختبار (pre-live) فيها سورتا الفاتحة والبقرة فقط؛ الإنتاج يحتاج حسابًا للبيئة الحقيقية.
- يُذكر Quran Foundation في وصف كل حلقة، والنص لا يُعدّل.

**Remotion: الرسم والرندر**

- تكوينان: `Episode` بمقاس 1920×1080 و`Short` بمقاس 1080×1920، يقرآن نفس `plan.json`.
- `calculateMetadata` يحسب مدة الفيديو من مجموع مدد الفصول في الخطة.
- الرندر عبر `renderMedia` من سكريبت Node، حلقة واحدة ثم شورتسها (بلا حد، D152).

**ffmpeg: الصوت النهائي**

- يدمج الصوت والمؤثرات والتلاوات بمستويات محددة.
- يضبط المستوى النهائي نحو ‎-14 LUFS بمرشح `loudnorm`.

## محرك المزامنة وتقطيع الشورتس

المزامنة كلها مشتقة من توقيتات الحروف؛ لا يُضبط أي توقيت يدويًا.

**خطوات المزامنة لكل فصل**

1. **من الحروف إلى الكلمات:** تُقسم مصفوفة الحروف عند المسافات؛ بداية الكلمة = بداية أول حرف فيها، ونهايتها = نهاية آخر حرف.
2. **استعادة الكتابة الأصلية:** النص المرسل للصوت قد يختلف عن نص الشاشة (تشكيل، تصحيحات القاموس). نحتفظ بخريطة كلمة بكلمة، فتظهر الترجمة بالكتابة الأصلية وتوقيت النطق.
3. **المقاطع:** يُقسم الفصل عند علامات الآيات إلى مقاطع تعليق تُولّد منفصلة، وتُدرج بينها الآية: بمدة تلاوتها المرخصة إن وُجدت، أو بمدة عرض محسوبة من طول نصها.
4. **حدود المشاهد:** كل علامة `[مشهد]` مرتبطة بأول كلمة بعدها؛ يبدأ المشهد مع نطق تلك الكلمة وينتهي مع بداية المشهد التالي.
5. **الترجمة على الشاشة:** الكلمات تُجمع في أسطر لا تتجاوز 7 كلمات، وتُكسر عند علامات الترقيم، وسطران كحد أقصى على الشاشة؛ الكلمة التي يقع الإطار الحالي داخل زمنها تُلوَّن.
6. **الحياة داخل المشهد:** المشهد الذي يطول عن 8 ثوانٍ يُظهر عناصره الفرعية مع بدايات الجمل، مع اقتراب بطيء للكاميرا.
7. **التحويل للإطارات:** 30 إطارًا في الثانية، والتوقيتات تُقرَّب لأقرب إطار.

**تقطيع الشورتس**

- كل فصل = شورت مستقل بتكوين `Short`، بنفس المشاهد بتخطيط 9:16.
- صوت جملة الربط لا يُضاف، فينتهي الشورت بخلاصة الفصل.
- آخر ثانيتين: بطاقة «الحلقة كاملة على القناة» بالشعار.
- مؤشر الفصول أعلى الشاشة يُظهر رقم الفصل من 6.

## الأسرار والإعدادات

المفاتيح تعيش في ملف `.env` على جهازك فقط، ولا تدخل Git أبدًا.

```bash
ELEVENLABS_API_KEY=…
ELEVENLABS_VOICE_ID=…          # معرّف صوتك المستنسخ
ELEVENLABS_MODEL_ID=…          # يُحدد بعد الاختبار
QF_CLIENT_ID=…
QF_CLIENT_SECRET=…
QF_ENV=production              # أو prelive للاختبار
```

- الإعدادات غير السرية (سرعة الكلام المعايرة، إعدادات الصوت، مستويات المزج) في `config.json` داخل المستودع.
- ملف `.env.example` بالأسماء فقط، بلا قيم.
- المستودع خاص، والوصول إليه بالتحقق بخطوتين.

## التكلفة والأداء

**رصيد ElevenLabs (تقدير):** الحلقة نحو 900 كلمة، أي قرابة 5,500 حرف بالمسافات. أربع حلقات شهريًا مع إعادة توليد بنسبة 50% ≈ 33,000 حرف. خطة Creator فيها 121,000 وحدة رصيد شهريًا حسب صفحة الأسعار، فالهامش واسع حتى لو اختلف سعر الحرف حسب النموذج. الرقم الحقيقي يُقاس بعد أول حلقة.

**وقت الرندر:** يُقاس على جهازك في الحلقة التجريبية. Remotion يرندر بالتوازي على أنوية المعالج، والتخزين المؤقت يمنع إعادة رندر ما لم يتغير. إن كان بطيئًا نضيف الرندر السحابي لاحقًا.

**Quran Foundation:** الآيات تُخزن محليًا بعد أول جلب، فعدد الطلبات قليل جدًا.

## مراحل البناء ومعايير القبول

خمس مراحل خلال أسابيع البناء الثلاثة في خارطة الطريق، وكل مرحلة تنتهي بشيء تراه وتجربه.

| المرحلة | ما يُبنى | معيار القبول |
| --- | --- | --- |
| 1. الأساس | المستودع، ملفات الثيمات والخطوط والشعار، الشخصيات | لقطات ثابتة للشخصيات والشعار بالثيمات الأربعة تطابق لوحة الهوية |
| 2. السكريبت | `bal new` و`bal check` وصيغة السكريبت | سكريبت تجريبي يمر، وسكريبت خاطئ يُرفض برسائل واضحة بالعربية |
| 3. الصوت والآيات | `bal voice` و`bal quran` وقاموس النطق والتخزين المؤقت | فصل بصوتك مع توقيتات صحيحة، وآية بالرسم العثماني |
| 4. المشاهد | القوالب الـ12 بالمقاسين | كل قالب يعمل بالثيمات الأربعة في Remotion Studio |
| 5. المزامنة والرندر والحزمة | `bal plan` و`bal render` و`bal package` و`bal make` | الحلقة التجريبية كاملة وشورتساتها الستة تمر بالبوابات الأربع |

المرحلتان 1 و2 لا تحتاجان صوتك، فنبدأ بهما فورًا بينما تسجّل العينات.
