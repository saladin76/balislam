# مراجعة بصرية مضبوطة — AlleyTale directed مقابل automatic

الحالة: عينة مقارنة متاحة في Remotion Studio؛ **لم تُعتمد بصريًا بعد** ولا تمثل الحلقة كاملة.

## قبل البدء
- انتقل في جهاز Mac إلى نسخة فرع `chore/balislam-production-environment-v1` في مجلد عمل نظيف أو فرع مراجعة منفصل.
- لا تستخدم `reset --hard` أو `stash pop`، ولا تعدّل خطط الحلقات الأساسية لمجرد التجربة.
- شغّل `npm ci` عند الحاجة، ثم `npm run check`؛ هذه الاختبارات ليست بديلًا عن معاينة الرندر.

## عينة A/B
داخل Remotion Studio (`npm run studio`) افتح:
- `balislam-alley-automatic-review`: الكاميرا القديمة وقطع التأطير المتكرر؛
- `balislam-alley-directed-review`: الكاميرا ثابتة، دون قطع تلقائي أو خطوات زائدة.

المشهدان بنفس النص والتوقيت والشخصيات والأحداث. الاختلاف المقصود فقط هو نمط إخراج الكاميرا. هذه العينة تجريبية ولا تضيف إعدادات إلى `plan.json` الخاص بالحلقة.

## تصدير عينتين قصيرتين محليًا من Mac
```bash
cd ~/balislam
mkdir -p out/director-review
npx remotion render src/remotion/index.ts balislam-alley-automatic-review out/director-review/automatic.mp4
npx remotion render src/remotion/index.ts balislam-alley-directed-review out/director-review/directed.mp4
```
إذا فشل الرندر بسبب نقص Chrome/FFmpeg أو إعداد البيئة، سجّل الخطأ ولا تعتبر المراجعة مكتملة.

## معايير المقارنة
- ثبات إطار `directed` دون انجراف غير مبرر أو قطع وسط الجملة؛
- غياب خطوات الشخصية والإيماءات الإضافية الآلية، مع بقاء أحداث المعنى المرتبطة بالكلمات؛
- عدم تقدّم النتيجة البصرية على كلمة الراوي التي تكشفها؛
- سلامة الشكل العربي واتصال الحروف والتشكيل والهوامش؛
- راحة العين وسلامة التكوين وسلاسة الحركة في وضع `automatic` أيضًا؛
- تصوير القنوات الأخرى لا يتغير بتعديل مخصص لـ«بالإسلام».

## قبول الدمج
يستلزم دمج التعديل: اجتياز `npm run check` محليًا، نجاح رندر عينة A/B، مقارنة فعلية على شاشة وهاتف، مراجعة لقطة على الأقل للحوار/المجرد/الآية، وتسجيل قرار المخرج وأي إصلاح مطلوب. **لا يُعد تشغيل Vite وحده اختبار رندر.**
